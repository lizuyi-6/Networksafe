
## 实现功能：攻击测试时显示实时攻防信息和终端

### 目标
- **上半部分**：实时显示攻防信息（Agent 分析、决策依据、证据）
- **下半部分**：实时显示终端日志

### 修改内容

#### 1. 后端修改
- 在 Agent 分析过程中添加 WebSocket 事件广播
- 在攻击模拟 API 中添加实时事件推送
- 新增事件类型：`attack:start`, `agent:analysis`, `attack:result`

#### 2. 前端修改
- 重构 `AttackSimulator.tsx` 页面布局
- 上半部分：攻防信息面板（Agent 分析过程、决策、证据）
- 下半部分：实时终端（日志流）
- 添加 WebSocket 连接，接收实时事件
- 支持逐步显示每个攻击的分析过程

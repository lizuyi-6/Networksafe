## 问题诊断总结

经过全面排查，发现以下核心问题：

### 1. Demo 模式问题
- `localStorage.demo_mode === 'true'` 时，所有 API 返回模拟数据
- 需要确保关闭 Demo 模式

### 2. API 路径不匹配
| 前端调用 | 后端真实数据位置 |
|---------|----------------|
| `/api/traffic/*` | `/api/ai-system/traffic/*` |
| `/api/agents/stats` | `/api/ai-system/agents/stats` |
| `/api/agents/health` | `/api/ai-system/agents/health` |

### 3. 后端返回硬编码假数据
- `traffic.routes.ts` - 全是假数据
- `logs.routes.ts` - 全是假数据
- `sites.routes.ts` - 全是假数据
- `admin.controller.ts` - 模拟数据

### 4. 缺失的后端端点
- `/api/alerts` - 不存在

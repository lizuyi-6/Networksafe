# AI 决策架构重构计划：7层多智能体协作系统

## 一、架构概览

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        FluxGuard Multi-Agent Decision System                 │
├─────────────────────────────────────────────────────────────────────────────┤
│  L7 ┌─────────────────────────────────────────────────────────────────────┐ │
│     │  分布式容错与合成 (Synthesis) - 自我进化、案件档案生成              │ │
│  L6 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  异构模型协作 (MoE) - 本地轻量模型 + 云端大模型仲裁                 │ │
│  L5 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  辩论协议 (Debate) - 红蓝对抗、证据交换、仲裁者裁决                │ │
│  L4 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  能力化身 (Capability) - 工具调用、安全执行 EXPLAIN SQL            │ │
│  L3 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  场景穿越 (Scene Traversal) - 分布式追踪、攻击叙事拼接             │ │
│  L2 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  角色扮演 (Role Playing) - 苏格拉底(红) / 柏拉图(蓝) / 亚里士多德  │ │
│  L1 ├─────────────────────────────────────────────────────────────────────┤ │
│     │  多智能体协作 (Collaboration) - 流量分发、专家智能体路由           │ │
│     └─────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 四、关键技术决策

1. **模型选择**：
   - 本地模型：Ollama + Llama-3-8B 量化版
   - 云端模型：智谱 GLM-4 / OpenAI GPT-4

2. **通信机制**：
   - 智能体间：内存消息总线（可扩展为 Redis）
   - 辩论协议：结构化 JSON 消息

3. **安全考虑**：
   - 工具执行：沙箱隔离
   - 模型调用：输入脱敏
   - 辩论结果：审计日志

# AetherGuard Deployment Dongle - 外壳设计规范

**版本**: v7.0
**日期**: 2026-03-13
**当前基线**: 平顶玻璃黑盒风格的桌面串口部署器外壳。旧的楔形壳体、直插 USB-A 壳体和滑盖方案仅保留为历史参考。

## 1. 设计目标

- 顶窗朝上，0.5m 到 1m 范围内可快速识别 OLED 状态。
- 通过右侧后下短线接入目标主机，避免机身因直插受力翻转。
- 采用完整外观壳 + 内托盘分工，不让内部柱体和门锁结构暴露在主视角。
- 继续兼容现有 `52mm x 29mm` ESP32 串口部署器 PCB，不引入电池仓。

## 2. 分件结构

- `LOWER_CHASSIS`: 内托盘、PCB 基准、压线柱、底门结构。
- `UPPER_BEZEL`: 完整平顶黑盒外观壳、统一顶窗、前侧按钮带、Type-C 开孔和右后下出线遮蔽。
- `SERVICE_DOOR`: 底部检修盖，隐藏式螺丝固定。
- `LENS`: 1.5mm 烟色透明窗片。
- `BUTTON_CAPS`: 3 个低矮按钮帽。

## 3. 关键尺寸

| 项目 | 尺寸 |
| :--- | :--- |
| 机身包络 | `90 x 58 x 16.8mm` |
| OLED 视窗 | `23 x 12mm` |
| RGB 透光 | `3.0mm` |
| 顶窗外观 | `81 x 47mm` |
| 三键中心距 | `12mm` |
| Type-C | `9 x 4mm` |
| 主机短线 | 适配 `3.2 - 3.8mm` 线径 |
| 蜂鸣器 | `3 x 1.5mm` 阵列孔 |

## 4. 外观约束

- 顶面不得出现裸露螺丝。
- 主视角必须读成一个连续低矮黑盒，不得出现平板叠放感。
- 整块顶窗必须成为第一视觉中心，不能退化回“小窗口 + 散点孔位”。
- 三键必须位于前侧长边，不得回到顶面。
- 右侧后下短线出线必须是下切或下凹表达，不得在主视角形成大号直槽。

## 5. 打印建议

- 主体推荐 `PLA+` 或 `PETG`。
- 常规层高 `0.2mm`，透明件与按钮帽可按 `0.12mm` 细化。
- 按钮帽建议高填充，主体 `20% - 30%` 即可。
- 开孔与卡装位置默认预留 `+0.2mm` 打印补偿。

## 6. 当前文件接口

- 主入口: `hardware/enclosure.scad`
- 兼容入口: `hardware/chassis.scad`, `hardware/top_plate.scad`, `hardware/bottom_cover.scad`
- 独立入口: `hardware/lens.scad`, `hardware/button_caps.scad`

## 7. 视觉验收要求

- 外壳重构完成后，必须输出前 3/4、侧视、俯视、排版四张渲染图，再进行结构验收。
- 兼容渲染文件名保留为：
  - `hardware/renders/desk_wedge_front34.png`
  - `hardware/renders/desk_wedge_side.png`
  - `hardware/renders/desk_wedge_top.png`
  - `hardware/renders/desk_wedge_plate.png`
- 若渲染中仍能明显读出楔形旧方案、顶面散点按钮或弱化顶窗，则视为视觉验收不通过。

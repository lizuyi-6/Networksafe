## 一、市场背景与痛点

### 1.1 网络安全威胁的严峻现实

根据国家互联网应急中心（CNCERT）数据，2025年中国境内遭受网络攻击的服务器数量同比增长 **47%**，API 接口已成为黑客攻击的首要目标，占所有攻击入口的 **62%**。

**企业面临的核心痛点：**

| 痛点 | 现状描述 |
|------|---------|
| **静态规则失效** | 传统 WAF 依赖人工维护规则库，无法应对 AI 驱动的变形攻击 |
| **部署门槛高** | 传统安全产品需要专业安全工程师配置，中小企业难以承受 |
| **响应速度慢** | 从发现攻击到人工响应平均需要 **4.2 小时**，黄金处置窗口早已关闭 |
| **可见性不足** | 安全事件发生后难以溯源，无法还原攻击链路 |
| **硬件运维割裂** | 软件防护与硬件运维完全分离，极端情况下无法物理干预 |
| **合规成本高** | 等保 2.0 合规需要大量人力投入，中小企业难以独立完成 |

### 1.2 目标市场规模

- **中国网络安全市场规模（2025）**：约 **800 亿元**，年增长率 18%
- **API 安全细分市场**：约 **120 亿元**，年增长率 **35%**（高于行业均值）
- **目标客群**：拥有自建服务器的中大型企业、SaaS 服务商、政府机构、金融机构

## 三、核心创新点

### 🔬 创新一：Agent-Inside 主机层防御架构

**传统方案的局限：**  
传统 WAF 部署在网络边界（反向代理层），所有流量必须绕行经过 WAF 节点。这导致：
- 单点故障风险：WAF 宕机则所有防护失效
- 加密流量盲区：HTTPS 内部流量无法检测
- 延迟增加：流量绕行增加 10-50ms 额外延迟

**AetherGuard 的创新：**  
Agent 直接驻留于业务服务器内部，在操作系统层面拦截恶意行为，无需流量绕行。

```
传统 WAF：  外部流量 → [WAF 节点] → 业务服务器
AetherGuard：外部流量 → 业务服务器 + [内置 Agent]
```

**优势：**
- 无单点故障：每台服务器独立防御
- 零延迟增加：本地处理，无网络绕行
- 加密流量可见：在解密后的应用层检测

---

### 🔬 创新二：软硬件一体化安全运维

**行业首创：** 将 ESP32 微控制器与服务器安全防护深度集成，实现"虚实结合"的安全运维新范式。

**ESP32 Deployment Dongle 的三重价值：**

1. **部署工具**：插入 USB 口，通过 OLED 屏幕和按键确认，自动完成 Agent 安装
2. **状态指示器**：通过 RGB LED 实时反映服务器安全状态（绿色=安全，红色=攻击中）
3. **物理断路器**：极端情况下按下物理按键，硬件级切断外部网络访问

这是业界**首个**将消费级硬件（ESP32，成本约 ¥30）与企业级安全防护深度融合的产品。

---

### 🔬 创新三：7 层多 Agent AI 决策系统

**传统 AI 安全的局限：**  
单一 AI 模型进行威胁判断，容易出现误报和漏报，且无法处理复杂的多步骤攻击链。

**AetherGuard 的创新：**  
构建了 7 层多 Agent 协作决策架构：

```
Layer 1: 多 Agent 协作层（Multi-Agent Collaboration）
Layer 2: 角色扮演层（Role Playing）- 红队/蓝队/分析师
Layer 3: 场景遍历层（Scene Traversal）
Layer 4: 能力实例化层（Capability Incarnation）
Layer 5: 辩论协议层（Debate Protocol）- 多模型交叉验证
Layer 6: 异构模型层（Heterogeneous Model）
Layer 7: 综合决策层（Synthesis）
```

多个 AI Agent 从不同角度分析同一威胁，通过"辩论"机制达成共识，显著降低误报率。

---

### 🔬 创新四：隐私优先的本地 AI 推理

**行业痛点：**  
云端 AI 分析需要将企业敏感的安全日志上传至第三方服务器，存在数据泄露风险。

**AetherGuard 的创新：**  
支持完全本地化的 AI 推理（通过 Ollama 框架），所有分析在企业私有网络内完成，数据永不离开企业边界。同时支持云端模型作为补充，用户可灵活选择。

---

### 🔬 创新五：攻击模拟即服务（Attack Simulation as a Service）

内置 35+ 种攻击类型的模拟器，企业可随时对自己的防御体系进行"压力测试"，验证防护有效性。这在传统安全产品中需要额外购买渗透测试服务（通常 ¥5-20 万/次）。

# 计算机软件著作权申请材料清单

根据中国版权保护中心（CPCC）的要求，申请软件著作权需要准备以下材料。我已经为您准备好了其中的 **用户手册** 和 **源代码** 文档。

## 1. 核心提交材料 (已为您准备)

### 1.1 软件操作说明书 (用户手册)
-   **文件位置**: `docs/软件操作说明书.md`
-   **说明**: 已按传统软著手册结构重构为 8 章正式源稿，章节固定为“软件概述、系统要求、安装部署、功能介绍、操作指南、常见问题、技巧与最佳实践、附录”，并保留 AetherGuard 当前版本的真实安装流程、真实运行截图和图号说明。
-   **篇幅目标**: 按 A4 纵向导出后建议不少于 20 页。
-   **截图目录**: `docs/screenshots/`
-   **截图构成**: 18 张运行界面截图 + 4 张安装过程截图，共 22 张；正文按图号统一引用，并保留登录页在安装章节与功能章节中的合理复用。
-   **要求**: 提交时建议转为 PDF 或 Word 格式，保持 A4 纵向排版，并核对页眉页脚与申请单位信息。

### 1.2 源代码文档 (60页)
-   **文件位置**: `docs/源代码_60页.txt`
-   **说明**: 包含前端核心源码 1500 行与后端核心源码 1500 行，共 3000 行，适用于 60 页排版；当前版本已按“核心业务优先”的原则重组节选窗口，前端覆盖路由、登录、总览、对象管理、流量、部署、扫描与 API 服务，后端覆盖入口、路由挂载、鉴权安全、设备接口、任务调度、安全操作、实时网关与输入校验。
-   **格式**: 已按软著材料口径整理为更高密度的核心业务代码节选，避免混入测试代码、构建产物、无关脚本和用于凑页数的空行。
-   **页眉/页脚**: 打印时请添加页眉（包含软件名称和版本号）和页码（1/60, 2/60...）。

## 2. 您需要额外准备的材料

### 2.1 计算机软件著作权登记申请表
-   **获取方式**: 需在中国版权保护中心官网 (http://www.ccopyright.com.cn/) 注册并在线填写。
-   **填写注意**:
    -   **软件全称**: AetherGuard
    -   **软件简称**: AetherGuard
    -   **版本号**: V1.0 (或您希望申请的版本，如 V2.1.0)
    -   **开发完成日期**: 填写实际完成开发的日期。
    -   **首次发表日期**: 如果未发表选择“未发表”，如已上线填写上线日期。
    -   **硬件环境**: 填写 `通用服务器 / ESP32嵌入式设备`。
    -   **软件环境**: 填写 `Linux / Windows`。
    -   **编程语言**: `TypeScript`。
    -   **源程序量**: 可填写 `3000` 行（与提交的 60 页源代码节选一致），也可按完整项目实际行数填写更高值。

### 2.2 身份证明文件
-   **企业申请**: 营业执照副本复印件（需加盖公章）。
-   **个人申请**: 身份证复印件（正反面）。

## 3. 打印与装订要求
1.  **纸张**: A4 纸单面打印。
2.  **份数**: 一式一份。
3.  **源代码**:
    -   除第 60 页外，每页不少于 50 行（已满足）。
    -   **不要装订**（不要使用订书机或胶装，通常要求散页或仅用夹子夹住，具体视代理机构要求，官方窗口受理通常不装订）。
4.  **签章**: 申请表第三页申请人签章处务必盖公章（企业）或签字（个人）。

祝您申请顺利！

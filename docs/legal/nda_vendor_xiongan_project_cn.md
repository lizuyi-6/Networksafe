## 第二条 保密信息定义

1. “保密信息”是指甲方、项目业主、项目相关主管部门或其授权主体向乙方披露，或者乙方在履约过程中知悉、接触、获取、推断形成的任何非公开信息，无论载体、形式或是否标注“保密”，包括但不限于：
   1. 项目信息：项目名称、招采信息、合同文本、预算、报价、项目计划、会议纪要、沟通记录、联系人、组织架构、验收标准、进度安排、项目风险、整改记录。
   2. 政府相关信息：与【河北雄安新区管理委员会/相关单位】有关的未公开文件、通知、会议材料、内部联系方式、账号信息、测试环境信息、系统配置、网络拓扑、审批流转、项目汇报材料、宣传口径。
   3. 技术信息：源代码、受限源码、接口协议、串口协议、数据结构、数据库结构、配置文件、架构设计、算法逻辑、模型参数、规则库、编译脚本、固件、硬件原理图、PCB、BOM、调试记录、漏洞信息、密钥管理方案、OTA 方案、物理确认流程、命令签名机制、安全策略。
   4. 数据信息：车辆遥测数据、设备标识、日志、告警、测试样本、脱敏前数据、接口报文、账号信息、认证信息、个人信息、敏感个人信息、重要数据、运营数据、审计日志、监控信息。
   5. 商务信息：客户名单、供应商信息、价格体系、商务条款、采购安排、融资信息、成本结构、营销计划、案例资料、对外合作方案。
   6. 其他信息：乙方基于前述信息分析、整理、演绎、汇总形成的方案、报告、代码、图纸、模型、样机、测试报告、截图、录音、录像、会议纪要。
2. 以下信息不属于保密信息，但乙方应承担举证责任：
   1. 在披露时已合法公开的信息。
   2. 乙方在披露前已合法持有且能提供书面证据的信息。
   3. 非因乙方违约而进入公共领域的信息。
   4. 乙方在未使用甲方保密信息前提下独立开发并能提供完整研发证据链的信息。
3. 即使信息未明确标注“保密”，但结合项目背景、政府合作属性、技术敏感性、是否包含个人信息或重要数据、是否限制流转等因素，足以判断其不宜公开的，均应按保密信息处理。

## 第三条 保密目的与授权边界

1. 乙方仅得为完成本项目经甲方书面确认的外包工作范围之目的使用保密信息，不得用于与本项目无关之任何目的。
2. 甲方当前授权边界以甲方书面清单为准，原则上仅限：
   1. 硬件/串口协议契约；
   2. 设备接入 DTO、命令枚举、状态机说明；
   3. 脱敏后的 companion 参考实现；
   4. 甲方指定的 mock 控制平面、测试证书、测试密钥、假数据、样例文档。
3. 甲方不向乙方开放以下内容，除非另有书面批准：
   1. 主仓库读写权限；
   2. 生产环境、预生产环境、政务环境或真实客户环境；
   3. 真实 API Key、设备密钥、证书、HSM、签名私钥、生产令牌；
   4. 完整数据库 schema、生产迁移脚本、真实日志、真实告警、真实固件包、真实客户数据；
   5. 鉴权、审计、租户、限流、命令签名、AI 决策、安全策略等核心实现细节。
4. 乙方不得通过接口探测、日志比对、逆向分析、缓存残留、环境变量枚举、网络抓包、人员套取等方式突破授权边界。

## 第四条 乙方保密义务

1. 乙方应采取不低于保护自身同类核心商业秘密的措施，且不得低于合理商业标准，对保密信息实施分级管理、最小权限控制、访问留痕、账号隔离、双因素认证、介质管控和定期审计。
2. 乙方仅可在甲方书面批准的工作环境、代码仓库、设备、账号和网络中处理保密信息。未经甲方书面同意，乙方不得：
   1. 将保密信息上传至公共代码托管平台、个人网盘、个人邮箱、即时通信群、论坛、工单系统或任何非甲方指定协作平台；
   2. 将保密信息输入、上传、粘贴或投喂至未获甲方书面批准的第三方 AI 模型、代码补全工具、训练平台、国外云服务或其他可能导致再利用、再训练、再分发的系统；
   3. 将保密信息存储于个人设备、移动硬盘、U 盘、个人手机、家用 NAS、未经批准的云主机；
   4. 复制、截图、录屏、拍照、下载、导出超出履约必要范围的保密信息；
   5. 向任何第三方披露项目名称、合作关系、项目内容，或在简历、官网、宣传资料、案例集、投标文件、社交媒体中使用甲方或【河北雄安新区管理委员会/相关单位】名称、标识、简称或暗示合作关系。
3. 乙方应确保接触保密信息的人员满足“知悉必要”原则，并至少履行以下管理义务：
   1. 形成经甲方确认的项目人员名单；
   2. 与全部接触人员签署不低于本协议标准的保密承诺；
   3. 对接触人员进行背景核验、权限审批、离岗交接与账号回收；
   4. 确保离职、转岗、外借人员不再接触项目资料；
   5. 应甲方要求提供人员清单、设备清单、访问日志及保密承诺存档。
4. 未经甲方书面同意，乙方不得将本项目任何部分转包、分包、转委托给第三方。

## 第五条 政府项目、涉密与数据合规特别条款

1. 双方确认：本协议不是任何“涉密资质”或“涉密授权”的替代文件，也不当然构成甲方向乙方开放国家秘密或依法不得对外披露信息的授权。
2. 如乙方发现甲方或项目相关材料中可能包含国家秘密、工作秘密、内部敏感文件、不宜公开的政府信息、重要数据、敏感个人信息、汽车数据或其他高敏感信息，乙方应立即停止处理，并在发现后 2 小时内书面通知甲方，待甲方书面指示后再处理。
3. 未经甲方书面同意且未满足法律法规要求，乙方不得：
   1. 将项目数据传输、备份或镜像至中华人民共和国境外；
   2. 允许境外主体、外籍人员或未授权人员访问项目资料；
   3. 处理超出项目必要范围的车辆位置、车外视频、车内音视频、人脸、语音、生物识别等数据；
   4. 在未做脱敏、去标识化、裁剪和权限控制前使用真实数据开展开发、测试、演示。
4. 如项目涉及政务云、专网、内网、涉密场所、重要信息基础设施、汽车数据或其他受特别监管场景，乙方应无条件配合甲方落实额外合规要求，包括但不限于场地检查、设备白名单、账号实名、终端加固、日志留存、数据分类分级、数据出境限制、删除证明、专项审计。

   4. 无条件配合甲方开展审计、调查、通知、整改、司法保全、监管报备。
2. 甲方有权在合理范围内对乙方保密管理、人员权限、代码仓库、日志记录、存储介质、数据流转情况进行审计或委托第三方审计。乙方应予配合，不得以商业秘密、内部制度或技术原因拒绝。

## 第八条 保密信息的返还、删除与销毁

1. 在甲方要求时、项目阶段结束时、合同终止或乙方人员退出项目时，乙方应在 3 个工作日内完成保密信息返还、删除、销毁和权限回收。
2. 删除、销毁范围包括但不限于源代码副本、缓存、临时文件、日志、下载文件、截图、录屏、打印件、移动介质、云端备份、镜像、测试数据、聊天记录中的附件。
3. 乙方完成返还、删除、销毁后，应向甲方出具书面确认函；甲方有权要求乙方补充提供删除截图、系统日志、设备清单、审计报告等证明材料。
4. 法律法规要求保留的资料，乙方应在最小必要范围内留存，并继续承担本协议项下全部保密义务。

1. 本协议自双方签字盖章之日起生效。
2. 乙方对一般保密信息的保密义务期限为自披露之日起 5 年。

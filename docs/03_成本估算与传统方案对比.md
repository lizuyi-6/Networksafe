## 一、传统服务器安全方案的成本构成

### 1.1 典型传统方案：硬件 WAF + 人工运维

以一家拥有 **10 台业务服务器**的中型企业为例：

#### 一次性成本

| 项目 | 单价 | 数量 | 小计 |
|------|------|------|------|
| 硬件 WAF 设备（如绿盟、启明星辰）| ¥80,000 | 1 台 | ¥80,000 |
| 部署实施服务费 | ¥20,000 | 1 次 | ¥20,000 |
| 安全培训费 | ¥10,000 | 1 次 | ¥10,000 |
| **一次性合计** | | | **¥110,000** |

#### 年度运营成本

| 项目 | 年费 |
|------|------|
| 硬件 WAF 年维保费（设备价格的 15%）| ¥12,000 |
| 规则库更新订阅 | ¥15,000 |
| 专职安全工程师（1人）| ¥200,000 |
| 年度渗透测试（外购）| ¥50,000 |
| 漏洞扫描服务（外购）| ¥30,000 |
| 等保合规咨询 | ¥30,000 |
| **年度运营合计** | **¥337,000** |

#### 3年总拥有成本（TCO）

```
TCO = 一次性成本 + 年度运营成本 × 3
    = ¥110,000 + ¥337,000 × 3
    = ¥1,121,000（约 112 万元）
```

## 五、ROI 分析

### 5.1 投资回报计算

以 Guardian 版（¥999/月）为例，与云 WAF 方案（¥270,000/年）对比：

```
年度节省 = 云 WAF 年费 - AetherGuard 年费
         = ¥270,000 - (¥11,988 + ¥20,000)
         = ¥238,012

投资回收期 = AetherGuard 年费 / 月节省额
           = ¥31,988 / (¥238,012 / 12)
           ≈ 1.6 个月
```

**投资回收期仅约 1.6 个月。**

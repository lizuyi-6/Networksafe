# 计算机软件著作权申请材料清单

根据中国版权保护中心（CPCC）的要求，申请软件著作权需要准备以下材料。我已经为您准备好了其中的 **用户手册** 和 **源代码** 文档。

## 1. 核心提交材料 (已为您准备)

### 1.1 软件操作说明书 (用户手册)
-   **文件位置**: `docs/软件操作说明书.md`
-   **说明**: 已包含软件功能概述、安装部署、各模块详细操作指南及硬件使用说明。
-   **要求**: 提交时建议转为 PDF 或 Word 格式，需配合截图（因目前文本中仅为描述，正式提交时建议您在对应位置插入实际软件截图）。

### 1.2 源代码文档 (60页)
-   **文件位置**: `docs/源代码_60页.txt`
-   **说明**: 包含后端 (NestJS)、前端 (React) 及硬件部分的核心代码。
-   **格式**: 已按要求去除了空行，约 3600 行，满足至少 60 页的要求。
-   **页眉/页脚**: 打印时请添加页眉（包含软件名称和版本号）和页码（1/60, 2/60...）。

## 2. 您需要额外准备的材料

### 2.1 计算机软件著作权登记申请表
-   **获取方式**: 需在中国版权保护中心官网 (http://www.ccopyright.com.cn/) 注册并在线填写。
-   **填写注意**:
    -   **软件全称**: FluxGuard Pro 智能服务器安全防御平台
    -   **软件简称**: FluxGuard Pro
    -   **版本号**: V1.0 (或您希望申请的版本，如 V2.1.0)
    -   **开发完成日期**: 填写实际完成开发的日期。
    -   **首次发表日期**: 如果未发表选择“未发表”，如已上线填写上线日期。
    -   **硬件环境**: 填写 `通用服务器 / ESP32嵌入式设备`。
    -   **软件环境**: 填写 `Linux / Windows`。
    -   **编程语言**: `TypeScript, Python, C++`。
    -   **源程序量**: 填写 `3628` 行 (参考值，可以填大概数如 10000 行，提交的代码只是部分)。

### 2.2 身份证明文件
-   **企业申请**: 营业执照副本复印件（需加盖公章）。
-   **个人申请**: 身份证复印件（正反面）。

## 3. 打印与装订要求
1.  **纸张**: A4 纸单面打印。
2.  **份数**: 一式一份。
3.  **源代码**:
    -   除第 60 页外，每页不少于 50 行（已满足）。
    -   **不要装订**（不要使用订书机或胶装，通常要求散页或仅用夹子夹住，具体视代理机构要求，官方窗口受理通常不装订）。
4.  **签章**: 申请表第三页申请人签章处务必盖公章（企业）或签字（个人）。

祝您申请顺利！

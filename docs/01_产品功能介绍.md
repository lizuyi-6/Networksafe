## 一、产品概述

**AetherGuard** 是一款面向企业级市场的**新一代智能服务器安全防御平台**。它突破了传统 WAF（Web 应用防火墙）的边界，采用"中心化控制 + 分布式执行 + 硬件级运维"三位一体的创新架构，将 AI 威胁分析、分布式 Agent 防护与 ESP32 硬件安全节点深度融合，为企业提供从网络边界到操作系统内核的全链路安全保障。

## 二、核心功能模块

### 🛡️ 1. 全局安全态势感知（Dashboard）

**功能定位：** 系统指挥中心，实时可视化呈现全局安全状态。

**核心能力：**
- **实时流量分析**：毫秒级展示请求量、拦截量、平均延迟、全局健康度四大核心指标
- **攻击来源地图**：可视化展示全球攻击来源分布，按国家/地区统计攻击占比
- **流量波形图**：正常流量 vs 被拦截请求的实时对比折线图，快速识别流量异常
- **实时日志流**：毫秒级滚动展示每条请求的状态码、类型、IP 和消息内容，支持关键词过滤
- **规则命中统计**：展示当前最活跃的安全规则及命中次数
- **API 密钥快览**：快速查看最新 API 密钥前缀及使用状态

---

### 🤖 2. 分布式 Agent 集群管理（Agents）

**功能定位：** 管理部署在各业务服务器上的安全 Agent 节点。

**核心能力：**
- **批量节点管理**：统一管理成百上千个分布在不同服务器的 Agent 实例
- **实时健康监控**：监控每个 Agent 的 CPU 占用、内存使用、运行状态和心跳时间
- **主机层防御**：Agent 直接驻留于业务服务器，提供操作系统级别的防护，无需流量绕行
- **自动注册上线**：新 Agent 部署后自动注册至控制台，无需手动配置
- **离线告警**：Agent 心跳超时自动触发告警，防止防护节点静默失效

---

### 🌐 3. 受保护站点管理（Sites）

**功能定位：** 管理所有接入防护的域名和业务服务。

**核心能力：**
- **多站点统一管理**：集中管理多个域名和 API 端点的防护策略
- **差异化策略配置**：为不同业务线（支付系统、公开 API、静态资源）配置独立的防护强度
- **AI 敏感度调节**：针对每个站点独立调整 AI 分析引擎的检测灵敏度
- **一键开关防护**：紧急情况下可快速暂停或恢复特定站点的防护模块
- **流量统计报表**：按站点维度展示请求量、拦截率等关键安全指标

---

### 🚀 4. 自动化部署向导（Deployment）

**功能定位：** 傻瓜式生成 Agent 安装脚本，降低运维门槛。

**核心能力：**
- **多操作系统支持**：自动生成适用于 Ubuntu、CentOS、Debian 的安装指令
- **可视化配置**：图形化填写服务器信息，无需手写配置文件
- **一键复制脚本**：运维人员只需复制一行命令即可完成服务器接入
- **配置文件下载**：支持下载完整配置文件，适配 CI/CD 自动化流程
- **部署状态追踪**：实时追踪部署进度，自动验证 Agent 是否成功上线

---

### 🔌 5. ESP32 硬件设备管理（Devices）

**功能定位：** 管理 ESP32 Deployment Dongle 和其他硬件安全节点。

**核心能力：**
- **硬件设备注册**：ESP32 设备插入服务器 USB 口后自动注册上线
- **远程状态监控**：实时查看设备 CPU 负载、内存使用、WiFi 信号强度（RSSI）
- **设备详情页（BoardStatus）**：专属的硬件监控界面，展示芯片型号、固件版本、运行模式
- **实时事件流**：展示设备上报的所有安全事件，支持实时追踪
- **物理断路控制**：通过硬件按键实现紧急物理断网，提供最后一道防线
- **AES-256 硬件加密**：ESP32-S3 安全元件提供硬件级加密运算，密钥永不离开芯片

---

### 🔍 6. 主动漏洞扫描（Scanner）

**功能定位：** 内置轻量级漏洞扫描引擎，主动发现安全隐患。

**核心能力：**
- **基于 Nuclei 引擎**：集成业界主流的开源漏洞扫描框架，覆盖 20,000+ 漏洞模板
- **20+ 安全基线检测**：自动检测 SSL 证书过期、敏感端口开放、HTTP 安全头缺失等
- **CVE 漏洞扫描**：定期扫描目标服务器的已知 CVE 漏洞
- **配置缺陷检测**：识别 Nginx/Apache 错误配置、目录遍历风险等
- **可读性报告**：扫描结束后生成通俗易懂的修复建议，而非晦涩的技术代码

---

### 📋 7. 安全事件历史（History）

**功能定位：** 记录所有安全事件和 AI 自动修复操作的完整历史。

**核心能力：**
- **完整攻击链路记录**：保留每次安全事件的完整上下文，支持取证溯源
- **AI 修复操作日志**：记录 AI 自动封禁 IP、修补漏洞的每一步操作流水
- **时间轴视图**：按时间线展示安全事件演变过程
- **合规审计导出**：支持导出符合等保 2.0 要求的审计报告

---

### 🔔 8. 实时告警中心（Alerts）

**功能定位：** 聚合所有节点的安全告警，实现精准预警。

**核心能力：**
- **多级别告警**：区分 INFO、WARN、HIGH、CRITICAL 四个威胁等级
- **智能降噪**：AI 过滤误报，将真正致命的威胁信号优先推送
- **多维度筛选**：按级别、来源、时间快速定位关键告警
- **多渠道推送**：支持邮件、Slack、Webhook 推送至运维群

---

### ⚙️ 9. AI 智能配置（Settings）

**功能定位：** 灵活配置 AI 分析引擎，平衡性能与隐私。

**核心能力：**
- **多模型支持**：支持接入 DeepSeek、GPT-4、Claude 等云端模型
- **本地 Ollama 集成**：支持完全本地化的 AI 推理，敏感数据不出私有网络
- **拖拽排序**：可视化拖拽调整模型优先级，灵活组合本地与云端算力
- **隐私模式**：一键切换"仅本地处理"模式，保障数据主权

---

### 👑 10. 超级管理员控制台（Admin）

**功能定位：** 系统级配置与多租户管理。

**核心能力：**
- **多租户管理**：为不同运维团队划分独立的资源空间
- **API 密钥管理**：颁发、撤销、查看各团队的访问密钥
- **性能配额控制**：限制每个租户的 API 调用频率，防止资源滥用
- **全局错误监控**：汇总所有租户的系统错误，快速定位问题
- **客户端性能报告**：监控 Agent 对业务服务器的性能影响（CPU 开销 < 2%）

---

### 🎯 11. 攻击模拟器（Attack Simulator）

**功能定位：** 内置攻击模拟工具，验证防御体系的有效性。

**核心能力：**
- **35+ 攻击类型**：覆盖 SQL 注入、XSS、路径遍历、命令注入、CSRF、SSRF、JWT 攻击等
- **实时分析面板**：模拟攻击的同时，实时展示 AI 决策过程和拦截结果
- **拦截率统计**：自动统计每次模拟的总攻击数、拦截数和拦截率
- **历史记录**：保留历次模拟结果，对比防御能力的变化趋势

---

### 📡 12. 流量拦截器（Traffic Interceptor）

**功能定位：** 深度网络流量分析与实时监控。

**核心能力：**
- **协议分布分析**：可视化展示 HTTP/HTTPS/WebSocket 等协议的流量占比
- **活跃连接追踪**：实时展示所有活跃网络连接的源/目标 IP、协议、状态
- **威胁检测统计**：按威胁类型（Critical/High/Medium/Low）分类展示检测结果
- **性能指标监控**：追踪丢包率、缓冲区溢出、平均处理时间等底层网络指标

---

### 🧠 13. 多 Agent AI 监控（Agent Monitor）

**功能定位：** 监控 7 层 AI 决策系统的运行状态。

**核心能力：**
- **7 层 AI 架构可视化**：展示多 Agent 协作、角色扮演、场景遍历、能力实例化等层次
- **Agent 心跳监控**：实时监控各 AI Agent 的健康状态（Healthy/Degraded/Unhealthy）
- **消息总线统计**：监控 AI 系统内部的消息队列、待处理请求、活跃任务数
- **案例文件管理**：追踪 AI 积累的经验案例、学习成果和策略更新记录

## 四、部署架构

```
外部流量
    ↓
[负载均衡]
    ↓
[业务服务器 + AetherGuard Agent]  ←→  [ESP32 硬件节点]
    ↓ WebSocket
[AetherGuard 控制平台]
    ├── SQLite/PostgreSQL 数据库
    ├── Redis 缓存
    └── AI 分析引擎（本地 Ollama / 云端 GPT-4）
```

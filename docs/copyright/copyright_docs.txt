## 1. 系统综述

FluxGuard Pro 是下一代**服务器安全防御平台**，旨在解决传统 WAF 无法防御的业务逻辑攻击与内部威胁。系统采用 "Agent-Hub" 架构，通过驻留在业务服务器上的轻量级 Agent 实时采集流量与系统调用，上报至中心化 Hub 进行 AI 分析与决策。

### 核心架构图
```mermaid
graph TD
    User[外部流量] --> ELB
    ELB --> LinuxNode["业务服务器 (Linux)"]
    
    subgraph "Edge Node (单机)"
        LinuxNode -- Hook --> Agent[FluxGuard Agent]
        Agent -- 采集 --> Metrics[系统指标]
        Agent -- 采集 --> Traffic[HTTP流量]
        Agent -- 执行 --> Firewall[IPTables阻断]
    end
    
    subgraph "Control Plane (集群)"
        Agent --> |gRPC/WS| Hub[管控中心]
        Hub --> AI[多模型分析引擎]
        Hub --> DB[(时序数据库)]
        
        Dashboard[可视化控制台] -- Read --> Hub
    end
```

## 2. 功能模块详解

### 2.1 全局态势感知 (Dashboard)
**功能**: 提供上帝视角的安全监控，展示系统的整体健康度与实时攻防状态。
**实现原理**: 
- 前端通过 WebSocket 订阅 `/topic/dashboard`。
- 后端 Redis 聚合每秒的 QPS、拦截数、活跃 Agent 数。
- **Screenshot Ref**: `dashboard.png`

![Dashboard](assets/dashboard.png)

### 2.2 智能 Agent 集群 (Agents)
**功能**: 分布式节点的注册、心跳保活与指令下发。
**实现原理**:
- 采用双向心跳机制 (Heartbeat Interval: 30s)。
- Agent 支持自升级与配置热加载。
- 状态机管理: Online / Offline / Warning / Critical (资源过载)。
- **Screenshot Ref**: `agents.png`

![Agents](assets/agents.png)

### 2.3 硬件化部署与运维 (Devices)
**功能**: 纳管 ESP32 部署工具 (Deployment Dongle)。
**实现原理**:
- ESP32 通过 WebSocket 连接网关。
- 采用 **Codebook 压缩协议** 降低带宽消耗，仅传输 4 字节状态码。
- 支持远程 OTA：用户上传固件 -> 后端推送 -> ESP32 自动写入 Flash。
- **Screenshot Ref**: `devices.png`

![Devices](assets/devices.png)

### 2.4 主动与被动扫描 (Scanner & Sites)
**功能**: 结合 Nuclei 的主动漏洞探测与基于流量的被动分析。
**实现原理**:
- **被动**: Agent 镜像流量 -> 正则/AI 匹配 (SQLi, XSS)。
- **主动**: 任务调度器定期下发 Nuclei 扫描任务 -> Agent 执行 -> 回传 JSON 报告。
- **Screenshot Ref**: `sites.png`, `scanner.png`

![Sites](assets/sites.png)
![Scanner](assets/scanner.png)

### 2.5 自动化部署向导 (Deployment)
**功能**: 降低 Agent 接入门槛。
**实现**:
- 动态生成带 Token 的 Install Script (Curl | Bash)。
- 自动检测 OS 类型 (Ubuntu/CentOS) 并适配安装命令。
- **Screenshot Ref**: `deploy.png`

![Deployment](assets/deploy.png)

### 2.6 AI 决策大脑 (Settings - AI Endpoint)
**功能**: 配置威胁分析引擎。
**技术细节**:
- 支持模型热切换: Local Ollama (Phi-3/Llama3) vs Cloud API (DeepSeek/GPT-4)。
- **Privacy Mode**: 开启后，仅在本机进行 Embedding，只有脱敏的 Vector 向量会被发送到云端（如果需要）。
- **Screenshot Ref**: `settings.png`

![Settings](assets/settings.png)

### 2.7 日志与审计 (History & Alerts)
**功能**: 满足企业合规性需求 (Compliance)。
**实现**:
- 不可篡改的日志存储 (Write-Once)。
- 告警风暴抑制算法 (Debounce)，防止同一 IP 触发海量告警。
- **Screenshot Ref**: `history.png`, `alerts.png`

![History](assets/history.png)
![Alerts](assets/alerts.png)

## 3. 硬件接口协议 (ESP32)

### 通信协议
- **物理层**: USB-TTL (Serial 115200 8N1)
- **协议层**: JSON Line 
  - 下行 (Web -> ESP): `{"cmd": "install", "url": "..."}`
  - 上行 (ESP -> Web): `{"status": "progress", "percent": 45}`

### 安全机制
- **Hard Confirmation**: 涉及 `rm -rf` 等指令时，ESP32 固件逻辑强制拦截，等待 GPIO 15 (BTN_OK) 物理高电平信号才能放行。

/**
 * Authentication Routes
 * 
 * Handles user registration, login, and token management
 */

import { Router, Response } from 'express';
import bcrypt from 'bcryptjs';
import { v4 as uuidv4 } from 'uuid';
import {
    AuthenticatedRequest,
    generateTokens,
    verifyRefreshToken,
    authenticate
} from '../../middleware/auth.middleware';
import { getDatabase } from '../../config/database';
import logger from '../../utils/logger';

const router = Router();

// Password validation
const PASSWORD_MIN_LENGTH = 8;
const EMAIL_REGEX = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

/**
 * POST /api/auth/register
 * Register a new user
 */
router.post('/register', async (req: AuthenticatedRequest, res: Response) => {
    try {
        const { email, password, username } = req.body;

        // Validate input
        if (!email || !password || !username) {
            return res.status(400).json({
                error: 'Email, password, and username are required',
                code: 'VALIDATION_ERROR'
            });
        }

        if (!EMAIL_REGEX.test(email)) {
            return res.status(400).json({
                error: 'Invalid email format',
                code: 'INVALID_EMAIL'
            });
        }

        if (password.length < PASSWORD_MIN_LENGTH) {
            return res.status(400).json({
                error: `Password must be at least ${PASSWORD_MIN_LENGTH} characters`,
                code: 'PASSWORD_TOO_SHORT'
            });
        }

        const db = getDatabase();

        // Check if user already exists
        const existingUser = db.prepare('SELECT id FROM users WHERE email = ?').get(email);
        if (existingUser) {
            return res.status(409).json({
                error: 'Email already registered',
                code: 'USER_EXISTS'
            });
        }

        // Hash password
        const saltRounds = 12;
        const passwordHash = await bcrypt.hash(password, saltRounds);

        // Create user
        const userId = uuidv4();
        const tenantId = uuidv4(); // Each user gets their own tenant by default
        const role = 'tenant'; // Default role

        db.prepare(`
      INSERT INTO users (id, email, username, password_hash, role, tenant_id, created_at)
      VALUES (?, ?, ?, ?, ?, ?, datetime('now'))
    `).run(userId, email, username, passwordHash, role, tenantId);

        // Generate tokens
        const tokens = generateTokens({
            userId,
            email,
            username,
            role,
            tenantId
        });

        logger.info(`New user registered: ${email}`);

        res.status(201).json({
            message: 'User registered successfully',
            user: {
                userId,
                email,
                username,
                role,
                tenantId
            },
            ...tokens
        });

    } catch (error: any) {
        logger.error('Registration error', { error: error.message });
        res.status(500).json({
            error: 'Registration failed',
            code: 'INTERNAL_ERROR'
        });
    }
});

        const { email, password } = req.body;

        if (!email || !password) {
            return res.status(400).json({
                error: 'Email and password are required',
                code: 'VALIDATION_ERROR'
            });
        }

        const db = getDatabase();

        // Find user
        const user = db.prepare(`
      SELECT id, email, username, password_hash, role, tenant_id, status
      FROM users WHERE email = ?
    `).get(email) as any;

        if (!user) {
            return res.status(401).json({
                error: 'Invalid credentials',
                code: 'INVALID_CREDENTIALS'
            });
        }

        // Check if account is active
        if (user.status === 'suspended') {
            return res.status(403).json({
                error: 'Account suspended',
                code: 'ACCOUNT_SUSPENDED'
            });
        }

        // Verify password
        const passwordValid = await bcrypt.compare(password, user.password_hash);
        if (!passwordValid) {
            logger.warn(`Failed login attempt for: ${email}`);
            return res.status(401).json({
                error: 'Invalid credentials',
                code: 'INVALID_CREDENTIALS'
            });
        }

        // Update last login
        db.prepare(`UPDATE users SET last_login = datetime('now') WHERE id = ?`).run(user.id);

        // Generate tokens
        const tokens = generateTokens({
            userId: user.id,
            email: user.email,
            username: user.username,
            role: user.role,
            tenantId: user.tenant_id
        });

        logger.info(`User logged in: ${email}`);

        res.json({
            message: 'Login successful',
            user: {
                userId: user.id,
                email: user.email,
                username: user.username,
                role: user.role,
                tenantId: user.tenant_id
            },
            ...tokens
        });

    } catch (error: any) {
        logger.error('Login error', { error: error.message });
        res.status(500).json({
            error: 'Login failed',
            code: 'INTERNAL_ERROR'
        });
    }
});

        const db = getDatabase();

        // Get user info
        const user = db.prepare(`
      SELECT id, email, username, role, tenant_id, status
      FROM users WHERE id = ?

                error: 'User not found or suspended',

    try {
        const { currentPassword, newPassword } = req.body;

        if (!currentPassword || !newPassword) {
            return res.status(400).json({
                error: 'Current and new password required',
                code: 'VALIDATION_ERROR'
            });
        }

        if (newPassword.length < PASSWORD_MIN_LENGTH) {
            return res.status(400).json({
                error: `Password must be at least ${PASSWORD_MIN_LENGTH} characters`,
                code: 'PASSWORD_TOO_SHORT'
            });
        }

        const db = getDatabase();

        // Get current password hash
        const user = db.prepare('SELECT password_hash FROM users WHERE id = ?')
            .get(req.user!.userId) as any;

        if (!user) {
            return res.status(404).json({ error: 'User not found' });
        }

        // Verify current password
        const passwordValid = await bcrypt.compare(currentPassword, user.password_hash);
        if (!passwordValid) {
            return res.status(401).json({
                error: 'Current password is incorrect',
                code: 'INVALID_PASSWORD'
            });
        }

        // Hash new password
        const newPasswordHash = await bcrypt.hash(newPassword, 12);

        // Update password
        db.prepare('UPDATE users SET password_hash = ?, updated_at = datetime(\'now\') WHERE id = ?')
            .run(newPasswordHash, req.user!.userId);

        logger.info(`Password changed for user: ${req.user?.email}`);

        res.json({
            message: 'Password changed successfully'
        });

    } catch (error: any) {
        logger.error('Password change error', { error: error.message });
        res.status(500).json({
            error: 'Password change failed',
            code: 'INTERNAL_ERROR'
        });
    }

// Honey pot field names (hidden fields that bots might fill)
const HONEYPOT_FIELD_NAME = 'website_confirm';

interface RequestFingerprint {
  ip: string;
  userAgent: string;
  acceptLanguage: string;
  acceptEncoding: string;
}

export class AntiBotMiddleware {
  private readonly REQUEST_THRESHOLD = 100; // requests per minute
  private readonly FAST_REQUEST_THRESHOLD = 10; // requests in 10 seconds
  private readonly BLOCK_DURATION = 3600; // 1 hour in seconds

  // Generate request fingerprint
  private generateFingerprint(req: Request): RequestFingerprint {
    return {
      ip: req.ip || req.connection.remoteAddress || 'unknown',
      userAgent: req.headers['user-agent'] || 'unknown',
      acceptLanguage: req.headers['accept-language'] || 'unknown',
      acceptEncoding: req.headers['accept-encoding'] || 'unknown',
    };
  }

  // Check if user agent is a known bot
  private isKnownBot(userAgent: string): boolean {
    return KNOWN_BOTS.some(bot => userAgent.toLowerCase().includes(bot));
  }

  // Check if user agent looks suspicious
  private isSuspiciousUserAgent(userAgent: string): boolean {
    // Empty user agent is suspicious
    if (!userAgent || userAgent.length < 10) {
      return true;
    }

    // Check against suspicious patterns
    return SUSPICIOUS_PATTERNS.some(pattern => pattern.test(userAgent));
  }

  // Check request rate using sliding window
  private async checkRequestRate(ip: string): Promise<{ allowed: boolean; rate: number }> {
    const key = `antibot:requests:${ip}`;
    const now = Date.now();
    const windowStart = now - 60000; // 1 minute window

    try {
      // Add current request timestamp
      await redisService.getClient().zadd(key, now, uuidv4());

      // Remove old entries outside the window
      await redisService.getClient().zremrangebyscore(key, 0, windowStart);

      // Count requests in the window
      const count = await redisService.getClient().zcard(key);

      // Set expiry
      await redisService.getClient().expire(key, 60);

      // Check fast request rate (10 requests in 10 seconds)
      const fastWindowStart = now - 10000;
      const fastCount = await redisService.getClient().zcount(key, fastWindowStart, now);

      // Determine if allowed
      const allowed = count < this.REQUEST_THRESHOLD && fastCount < this.FAST_REQUEST_THRESHOLD;

      return { allowed, rate: count };
    } catch (error) {
      logger.error('Error checking request rate', { error, ip });
      return { allowed: true, rate: 0 };
    }
  }

  // Check for fast sequential requests (possible automation)
  private async checkFastSequentialRequests(ip: string): Promise<boolean> {
    const key = `antibot:fast:${ip}`;
    const now = Date.now();

    try {
      const lastRequest = await redisService.get(key);
      if (lastRequest) {
        const timeSinceLastRequest = now - parseInt(lastRequest);
        // If requests are less than 100ms apart, it's likely automated
        if (timeSinceLastRequest < 100) {
          return true; // Suspicious
        }
      }

      // Update last request time
      await redisService.set(key, now.toString(), 10);
      return false;
    } catch (error) {
      logger.error('Error checking fast requests', { error, ip });
      return false;
    }
  }

  // Check honeypot field (if present in request body)
  private checkHoneypot(req: Request): boolean {
    if (req.body && typeof req.body === 'object') {
      const honeypotValue = req.body[HONEYPOT_FIELD_NAME];
      // If honeypot field is filled, it's likely a bot
      if (honeypotValue && honeypotValue.toString().trim().length > 0) {
        return true;
      }
    }
    return false;
  }

  // Block IP address
  private async blockIP(ip: string, reason: string): Promise<void> {
    const key = `antibot:blocked:${ip}`;
    try {
      await redisService.set(
        key,
        JSON.stringify({
          reason,
          blockedAt: new Date().toISOString(),
        }),
        this.BLOCK_DURATION
      );

      logger.warn('IP blocked for suspicious activity', { ip, reason });
    } catch (error) {
      logger.error('Error blocking IP', { error, ip });
    }
  }

  // Check if IP is blocked
  private async isIPBlocked(ip: string): Promise<boolean> {
    const key = `antibot:blocked:${ip}`;
    try {
      const blocked = await redisService.exists(key);
      return blocked;
    } catch (error) {
      logger.error('Error checking blocked IP', { error, ip });
      return false;
    }
  }

  // Main middleware function
  public protect = async (req: Request, res: Response, next: NextFunction): Promise<void> => {
    const fingerprint = this.generateFingerprint(req);
    const userAgent = fingerprint.userAgent.toLowerCase();

    try {
      // Skip all checks in development/test environment for testing purposes
      if (config.env !== 'production') {
        logger.debug('Skipping anti-bot checks in development environment', { ip: fingerprint.ip });
        next();
        return;
      }

      // Check if IP is already blocked
      const isBlocked = await this.isIPBlocked(fingerprint.ip);
      if (isBlocked) {
        logger.warn('Blocked IP attempted access', { ip: fingerprint.ip });
        res.status(429).json({
          error: 'Too many requests',
          message: 'Your access has been temporarily restricted due to suspicious activity',
        });
        return;
      }

      // Allow known good bots (Google, Bing, etc.)
      if (this.isKnownBot(userAgent)) {
        logger.debug('Known bot allowed', { ip: fingerprint.ip, userAgent: fingerprint.userAgent });
        next();
        return;
      }

      // Allow localhost/127.0.0.1/::1 for development
      if (fingerprint.ip === '127.0.0.1' || fingerprint.ip === '::1' || fingerprint.ip === 'localhost') {
        logger.debug('Localhost allowed', { ip: fingerprint.ip });
        next();
        return;
      }

      // Check for suspicious user agent
      if (this.isSuspiciousUserAgent(userAgent)) {
        await this.blockIP(fingerprint.ip, 'Suspicious user agent');
        logger.warn('Suspicious user agent blocked', { ip: fingerprint.ip, userAgent: fingerprint.userAgent });
        res.status(403).json({
          error: 'Access denied',
          message: 'Your request appears to be automated',
        });
        return;
      }

      // Check honeypot
      if (this.checkHoneypot(req)) {
        await this.blockIP(fingerprint.ip, 'Honeypot triggered');
        logger.warn('Honeypot triggered', { ip: fingerprint.ip });
        res.status(403).json({
          error: 'Access denied',
          message: 'Invalid request',
        });
        return;
      }

      // Check request rate
      const rateCheck = await this.checkRequestRate(fingerprint.ip);
      if (!rateCheck.allowed) {
        await this.blockIP(fingerprint.ip, `Rate limit exceeded: ${rateCheck.rate} req/min`);
        logger.warn('Rate limit exceeded', { ip: fingerprint.ip, rate: rateCheck.rate });
        res.status(429).json({
          error: 'Too many requests',
          message: 'Rate limit exceeded. Please slow down.',
          retryAfter: this.BLOCK_DURATION,
        });
        return;
      }

      // Check for fast sequential requests
      const isFastSequential = await this.checkFastSequentialRequests(fingerprint.ip);
      if (isFastSequential) {
        logger.warn('Fast sequential requests detected', { ip: fingerprint.ip });
        // Don't block immediately, but log the suspicious activity
      }

      // Check for missing required headers
      if (!req.headers['user-agent'] || !req.headers['accept']) {
        logger.warn('Missing required headers', { ip: fingerprint.ip, headers: req.headers });
        res.status(400).json({
          error: 'Bad request',
          message: 'Invalid request headers',
        });
        return;
      }

      // All checks passed
      next();
    } catch (error) {
      logger.error('Error in anti-bot middleware', { error, ip: fingerprint.ip });
      // Fail open to avoid blocking legitimate traffic on error
      next();
    }
  };

  // Get honeypot field name (for use in forms)
  public static getHoneypotFieldName(): string {
    return HONEYPOT_FIELD_NAME;
  }
}

export interface PasswordPolicy {
  minLength: number;
  requireUppercase: boolean;
  requireLowercase: boolean;
  requireNumbers: boolean;
  requireSpecialChars: boolean;
  maxLength?: number;
}

export interface LoginAttempt {
  email: string;
  ip: string;
  success: boolean;
  timestamp: number;
}

export class AuthSecurityService {
  private readonly MAX_LOGIN_ATTEMPTS = 5;
  private readonly LOCKOUT_DURATION = 900; // 15 minutes in seconds
  private readonly ATTEMPT_WINDOW = 300; // 5 minutes in seconds

  private readonly PASSWORD_POLICY: PasswordPolicy = {
    minLength: 8,
    requireUppercase: true,
    requireLowercase: true,
    requireNumbers: true,
    requireSpecialChars: true,
    maxLength: 128,
  };

  private readonly COMMON_PASSWORDS = [
    'password', '123456', '12345678', 'qwerty', 'abc123',
    'monkey', 'master', 'dragon', '111111', 'baseball',
    'iloveyou', 'trustno1', 'sunshine', 'princess', 'admin',
    'welcome', 'shadow', 'ashley', 'football', 'jesus',
    'michael', 'ninja', 'mustang', 'password1', 'password123',
  ];

  private readonly SUSPICIOUS_PATTERNS = [
    /1234.*56/, // Sequential numbers
    /abcd.*ef/, // Sequential letters
    /qwerty.*uiop/, // Keyboard patterns
    /(.+)\1{2,}/, // Repeated characters (aaa111)
  ];

  // Check password strength
  public validatePassword(password: string): { valid: boolean; errors: string[]; strength: string } {
    const errors: string[] = [];
    let strength = 'weak';

    // Check length
    if (password.length < this.PASSWORD_POLICY.minLength) {
      errors.push(`Password must be at least ${this.PASSWORD_POLICY.minLength} characters long`);
    } else if (password.length >= 12) {
      strength = 'strong';
    } else if (password.length >= 8) {
      strength = 'medium';
    }

    // Check max length
    if (this.PASSWORD_POLICY.maxLength && password.length > this.PASSWORD_POLICY.maxLength) {
      errors.push(`Password must not exceed ${this.PASSWORD_POLICY.maxLength} characters`);
    }

    // Check uppercase
    if (this.PASSWORD_POLICY.requireUppercase && !/[A-Z]/.test(password)) {
      errors.push('Password must contain at least one uppercase letter');
    }

    // Check lowercase
    if (this.PASSWORD_POLICY.requireLowercase && !/[a-z]/.test(password)) {
      errors.push('Password must contain at least one lowercase letter');
    }

    // Check numbers
    if (this.PASSWORD_POLICY.requireNumbers && !/\d/.test(password)) {
      errors.push('Password must contain at least one number');
    }

    // Check special characters
    if (this.PASSWORD_POLICY.requireSpecialChars && !/[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?]/.test(password)) {
      errors.push('Password must contain at least one special character');
    }

    // Check against common passwords
    if (this.COMMON_PASSWORDS.includes(password.toLowerCase())) {
      errors.push('Password is too common');
      strength = 'weak';
    }

    // Check for suspicious patterns
    for (const pattern of this.SUSPICIOUS_PATTERNS) {
      if (pattern.test(password)) {
        errors.push('Password contains predictable patterns');
        strength = 'weak';
        break;
      }
    }

    return {
      valid: errors.length === 0,
      errors,
      strength,
    };
  }

  // Record login attempt
  public async recordLoginAttempt(email: string, ip: string, success: boolean): Promise<void> {
    const key = `auth:attempts:${email.toLowerCase()}`;

    try {
      const attempt: LoginAttempt = {
        email: email.toLowerCase(),
        ip,
        success,
        timestamp: Date.now(),
      };

      // Add attempt to Redis list
      await redisService.getClient().lpush(key, JSON.stringify(attempt));

      // Remove old attempts outside the window
      const cutoffTime = Date.now() - (this.ATTEMPT_WINDOW * 1000);
      const attempts = await redisService.getClient().lrange(key, 0, -1);

      // Filter and keep only recent attempts
      const recentAttempts = attempts
        .map(a => {
          try {
            return JSON.parse(a);
          } catch {
            return null;
          }
        })
        .filter((a: LoginAttempt | null) => a !== null && a.timestamp > cutoffTime) as LoginAttempt[];

      // Clear and repopulate with recent attempts
      await redisService.del(key);
      for (const a of recentAttempts.reverse()) {
        await redisService.getClient().rpush(key, JSON.stringify(a));
      }

      // Set expiry
      await redisService.getClient().expire(key, this.ATTEMPT_WINDOW);

      // If failed attempt, check if we need to lock the account
      if (!success) {
        await this.checkAndLockAccount(email, ip);
      }
    } catch (error) {
      logger.error('Error recording login attempt', { error, email });
    }
  }

  // Check and lock account if too many failed attempts
  private async checkAndLockAccount(email: string, ip: string): Promise<void> {
    const key = `auth:attempts:${email.toLowerCase()}`;

    try {
      const attempts = await redisService.getClient().lrange(key, 0, -1);
      const failedAttempts = attempts
        .map(a => {
          try {
            return JSON.parse(a);
          } catch {
            return null;
          }
        })
        .filter((a: LoginAttempt | null): a is LoginAttempt => a !== null && !a.success);

      if (failedAttempts.length >= this.MAX_LOGIN_ATTEMPTS) {
        // Lock the account
        const lockKey = `auth:locked:${email.toLowerCase()}`;
        await redisService.set(
          lockKey,
          JSON.stringify({
            reason: `Too many failed login attempts (${this.MAX_LOGIN_ATTEMPTS})`,
            lockedAt: new Date().toISOString(),
            attempts: failedAttempts.slice(0, this.MAX_LOGIN_ATTEMPTS),
          }),
          this.LOCKOUT_DURATION
        );

        logger.error('Account locked due to too many failed attempts', {
          email,
          ip,
          attempts: failedAttempts.length,
        });
      }
    } catch (error) {
      logger.error('Error checking account lock', { error, email });
    }
  }

  // Check if account is locked
  public async isAccountLocked(email: string): Promise<boolean> {
    const key = `auth:locked:${email.toLowerCase()}`;

    try {
      return await redisService.exists(key);
    } catch (error) {
      logger.error('Error checking account lock', { error, email });
      return false;
    }
  }

  // Get lock information
  public async getLockInfo(email: string): Promise<{ locked: boolean; reason?: string; remainingTime?: number }> {
    const key = `auth:locked:${email.toLowerCase()}`;

    try {
      const lockData = await redisService.get(key);
      if (!lockData) {
        return { locked: false };
      }

      const ttl = await redisService.getClient().ttl(key);
      const lock = JSON.parse(lockData);

      return {
        locked: true,
        reason: lock.reason,
        remainingTime: ttl > 0 ? ttl : 0,
      };
    } catch (error) {
      logger.error('Error getting lock info', { error, email });
      return { locked: false };
    }
  }

  // Unlock account (admin only or after lockout period)
  public async unlockAccount(email: string): Promise<void> {
    const key = `auth:locked:${email.toLowerCase()}`;

    try {
      await redisService.del(key);
      logger.info('Account unlocked', { email });
    } catch (error) {
      logger.error('Error unlocking account', { error, email });
    }
  }

  // Check IP for multiple failed login attempts (possible brute force)
  public async checkIPBruteForce(ip: string): Promise<boolean> {
    const key = `auth:ip:attempts:${ip}`;

    try {
      const attempts = await redisService.getClient().lrange(key, 0, -1);
      const recentAttempts = attempts
        .map(a => {
          try {
            return JSON.parse(a);
          } catch {
            return null;
          }
        })
        .filter((a: LoginAttempt | null): a is LoginAttempt => {
          if (!a) return false;
          const timeSinceAttempt = Date.now() - a.timestamp;
          return timeSinceAttempt < (this.ATTEMPT_WINDOW * 1000);
        });

      // If more than 10 failed attempts from same IP, it's suspicious
      const failedAttempts = recentAttempts.filter((a: LoginAttempt) => !a.success);
      if (failedAttempts.length > 10) {
        logger.error('Possible brute force attack detected', {
          ip,
          attempts: failedAttempts.length,
        });
        return true;
      }

      return false;
    } catch (error) {
      logger.error('Error checking IP brute force', { error, ip });
      return false;
    }
  }

  // Get failed login attempts for monitoring
  public async getFailedAttempts(email: string): Promise<LoginAttempt[]> {
    const key = `auth:attempts:${email.toLowerCase()}`;

    try {
      const attempts = await redisService.getClient().lrange(key, 0, -1);
      return attempts
        .map(a => {
          try {
            return JSON.parse(a);
          } catch {
            return null;
          }
        })
        .filter((a: LoginAttempt | null): a is LoginAttempt => a !== null && !a.success);
    } catch (error) {
      logger.error('Error getting failed attempts', { error, email });
      return [];
    }
  }

  // Detect suspicious login behavior
  public async detectSuspiciousLogin(req: Request, email: string): Promise<string[]> {
    const warnings: string[] = [];
    const ip = req.ip || req.connection.remoteAddress || 'unknown';

    // Check if account is locked
    const isLocked = await this.isAccountLocked(email);
    if (isLocked) {
      const lockInfo = await this.getLockInfo(email);
      warnings.push(`Account is locked: ${lockInfo.reason}`);
    }

    // Check IP for brute force
    const isBruteForce = await this.checkIPBruteForce(ip);
    if (isBruteForce) {
      warnings.push('Multiple failed login attempts detected from your IP');
    }

    // Check for unusual login time (optional)
    const hour = new Date().getHours();
    if (hour >= 2 && hour <= 5) {
      // Logins between 2-5 AM are suspicious
      warnings.push('Unusual login time detected');
    }

    // Check User-Agent consistency (optional enhancement)
    const userAgent = req.headers['user-agent'];
    if (!userAgent || userAgent.length < 10) {
      warnings.push('Invalid User-Agent');
    }

    return warnings;
  }

  // Generate session ID for additional security
  public generateSessionId(): string {
    return `${Date.now()}-${Math.random().toString(36).substring(2, 15)}`;
  }

  // Validate session
  public async validateSession(userId: string, sessionId: string): Promise<boolean> {
    const key = `auth:session:${userId}`;

    try {
      const storedSessionId = await redisService.get(key);
      return storedSessionId === sessionId;
    } catch (error) {
      logger.error('Error validating session', { error, userId });
      return false;
    }
  }

  // Invalidate session (logout)
  public async invalidateSession(userId: string): Promise<void> {
    const key = `auth:session:${userId}`;

    try {
      await redisService.del(key);
      logger.info('Session invalidated', { userId });
    } catch (error) {
      logger.error('Error invalidating session', { error, userId });
    }
  }

  // Check for concurrent sessions
  public async checkConcurrentSessions(userId: string, maxSessions: number = 3): Promise<boolean> {
    const key = `auth:concurrent:${userId}`;

    try {
      const sessionCount = await redisService.getClient().scard(key);
      return sessionCount < maxSessions;
    } catch (error) {
      logger.error('Error checking concurrent sessions', { error, userId });
      return true;
    }
  }

  // Add session
  public async addSession(userId: string, sessionId: string, deviceInfo: Record<string, unknown>): Promise<void> {
    const key = `auth:concurrent:${userId}`;

    try {
      await redisService.getClient().sadd(key, sessionId);
      await redisService.getClient().expire(key, 86400); // 24 hours

      // Store session details
      const sessionKey = `auth:session:${sessionId}`;
      await redisService.set(
        sessionKey,
        JSON.stringify({
          userId,
          deviceInfo,
          createdAt: Date.now(),
        }),
        86400
      );
    } catch (error) {
      logger.error('Error adding session', { error, userId });
    }
  }

  // Remove session
  public async removeSession(userId: string, sessionId: string): Promise<void> {
    const key = `auth:concurrent:${userId}`;
    const sessionKey = `auth:session:${sessionId}`;

    try {
      await redisService.getClient().srem(key, sessionId);
      await redisService.del(sessionKey);
    } catch (error) {
      logger.error('Error removing session', { error, userId });
    }
  }
}

/**
 * Concurrency control middleware for high-traffic scenarios
 * Prevents server overload and ensures fair resource allocation
 */

interface QueueItem {
  resolve: () => void;
  reject: (error: any) => void;
  timestamp: number;
}

class ConcurrencyController {
  private userQueues = new Map<string, QueueItem[]>();
  private activeRequests = new Map<string, number>();
  // Use locks to prevent race conditions
  private locks = new Map<string, Promise<void>>();

  /**
   * Acquire request slot for user (thread-safe)
   */
  async acquireSlot(userId: string): Promise<void> {
    // Wait for any existing operation on this user to complete
    let existingLock = this.locks.get(userId);
    while (existingLock) {
      await existingLock;
      existingLock = this.locks.get(userId);
    }

    // Create a new lock for this operation
    let resolveLock: (() => void) | undefined;
    const lockPromise = new Promise<void>(resolve => { resolveLock = resolve; });
    this.locks.set(userId, lockPromise);

    try {
      const active = this.activeRequests.get(userId) || 0;

      if (active < CONCURRENCY.MAX_CONCURRENT_REQUESTS_PER_USER) {
        // Slot available - atomic increment
        this.activeRequests.set(userId, active + 1);
        return;
      }

      // Wait in queue
      return new Promise((resolve, reject) => {
        let queue = this.userQueues.get(userId);

        if (!queue) {
          queue = [];
          this.userQueues.set(userId, queue);
        }

        // Check queue size limit
        if (queue.length >= CONCURRENCY.MAX_QUEUE_SIZE) {
          reject(new Error('Request queue full'));
          return;
        }

        queue.push({
          resolve: resolve as () => void,
          reject,
          timestamp: Date.now(),
        });
      });
    } finally {
      // Release the lock
      if (resolveLock) {
        resolveLock();
      }
      this.locks.delete(userId);
    }
  }

  /**
   * Release request slot for user
   */
  releaseSlot(userId: string): void {
    const active = this.activeRequests.get(userId) || 0;

    if (active > 0) {
      this.activeRequests.set(userId, active - 1);
    }

    // Process next request in queue
    const queue = this.userQueues.get(userId);

    if (queue && queue.length > 0) {
      const next = queue.shift();
      this.activeRequests.set(userId, (this.activeRequests.get(userId) || 0) + 1);
      next?.resolve();
    }
  }

  /**
   * Get current statistics
   */
  getStats(userId: string) {
    return {
      active: this.activeRequests.get(userId) || 0,
      queued: (this.userQueues.get(userId) || []).length,
    };
  }

  /**
   * Cleanup inactive users to prevent memory leaks
   */
  cleanup(): void {
    const now = Date.now();
    const staleThreshold = now - (60 * 60 * 1000); // 1 hour

    for (const [userId, queue] of this.userQueues.entries()) {
      const active = this.activeRequests.get(userId) || 0;
      const hasStaleRequests = queue.some(item => item.timestamp < staleThreshold);

      // Clean up if no active requests and only stale queued requests
      if (active === 0 && hasStaleRequests) {
        this.userQueues.delete(userId);
        this.activeRequests.delete(userId);
      }
    }
  }
}

const controller = new ConcurrencyController();

/**
 * Concurrency limiting middleware
 */
export const concurrencyLimit = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  const userId = (req as any).user?.userId || 'anonymous';

  try {
    // Acquire slot
    await controller.acquireSlot(userId);

    logger.debug('Request slot acquired', { userId });

    // Release slot after response
    res.on('finish', () => {
      controller.releaseSlot(userId);
      logger.debug('Request slot released', { userId });
    });

    next();
  } catch (error) {
    logger.warn('Concurrency limit exceeded', { userId, error });

    res.status(429).json({
      success: false,
      error: {
        message: 'Too many concurrent requests. Please retry later.',
        type: 'concurrency_limit_exceeded',
      },
    });
  }
};

/**
 * Performance monitoring middleware
 */
export const performanceMonitor = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  if (!MONITORING.ENABLE_PERFORMANCE_TRACKING) {
    next();
    return;
  }

  const startTime = Date.now();
  const startMemory = process.memoryUsage();

  // Track response
  const originalJson = res.json.bind(res);

  res.json = function (body: any) {
    const endTime = Date.now();
    const duration = endTime - startTime;
    const endMemory = process.memoryUsage();
    const memoryUsed = (endMemory.heapUsed - startMemory.heapUsed) / 1024 / 1024; // MB

    // Log slow requests
    if (duration > MONITORING.SLOW_QUERY_THRESHOLD) {
      logger.warn('Slow request detected', {
        url: req.url,
        method: req.method,
        duration,
        memoryUsed: `${memoryUsed.toFixed(2)}MB`,
      });
    } else {
      logger.debug('Request completed', {
        url: req.url,
        method: req.method,
        duration,
        memoryUsed: `${memoryUsed.toFixed(2)}MB`,
      });
    }

    // Add performance headers
    res.setHeader('X-Response-Time', `${duration}ms`);

    return originalJson(body);
  };

  next();
};

/**
 * Memory usage monitoring
 */
export function startMemoryMonitoring(): void {
  // Clear existing interval if any
  if (memoryMonitorInterval) {
    clearInterval(memoryMonitorInterval);
  }

  memoryMonitorInterval = setInterval(() => {
    const memory = process.memoryUsage();
    const heapUsedMB = memory.heapUsed / 1024 / 1024;

    if (heapUsedMB > MONITORING.MEMORY_WARNING_THRESHOLD) {
      logger.warn('High memory usage detected', {
        heapUsed: `${heapUsedMB.toFixed(2)}MB`,
        heapTotal: `${(memory.heapTotal / 1024 / 1024).toFixed(2)}MB`,
        external: `${(memory.external / 1024 / 1024).toFixed(2)}MB`,
      });
    }
  }, 30000); // Check every 30 seconds
}

/**
 * CPU usage monitoring
 */
export function startCPUMonitoring(): void {
  // Clear existing interval if any
  if (cpuMonitorInterval) {
    clearInterval(cpuMonitorInterval);
  }

  // Reset baseline each time monitoring starts
  let startUsage = process.cpuUsage();

  cpuMonitorInterval = setInterval(() => {
    const usage = process.cpuUsage(startUsage);
    const userUsage = usage.user / 1000000; // Convert to seconds
    const systemUsage = usage.system / 1000000;

    logger.debug('CPU usage', {
      user: `${userUsage.toFixed(2)}s`,
      system: `${systemUsage.toFixed(2)}s`,
    });

    // Reset baseline for next interval
    startUsage = process.cpuUsage();
  }, 30000); // Check every 30 seconds
}

/**
 * Stop all monitoring intervals (for cleanup)
 */
export function stopMonitoring(): void {
  if (memoryMonitorInterval) {
    clearInterval(memoryMonitorInterval);
    memoryMonitorInterval = null;
  }
  if (cpuMonitorInterval) {
    clearInterval(cpuMonitorInterval);
    cpuMonitorInterval = null;
  }
}

function setRateLimitHeaders(
  res: Response,
  limit: number,
  remaining: number,
  resetTime: number

// Rate limit middleware using Redis
export const rateLimitMiddleware = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  try {
    if (!(req as any).apiKey) {
      next();
      return;
    }

    const { userId, rateLimit } = (req as any).apiKey;
    const limit = rateLimit.requestsPerMinute;

    // Create rate limit keys
    const requestCountKey = `${REDIS_KEYS.RATE_LIMIT_PREFIX}:${userId}:${REDIS_KEYS.REQUEST_COUNT_SUFFIX}`;
    const requestLimitKey = `${REDIS_KEYS.RATE_LIMIT_PREFIX}:${userId}:${REDIS_KEYS.LIMIT_SUFFIX}`;
    const windowKey = `${REDIS_KEYS.RATE_LIMIT_PREFIX}:${userId}:${REDIS_KEYS.WINDOW_SUFFIX}`;

    const now = Date.now();

    // Use atomic increment with expiry to prevent race conditions
    const client = redisService.getClient();

    // Get current window info
    const currentWindow = await redisService.get(windowKey);

    if (!currentWindow) {
      // Start new window atomically
      const multi = client.multi();
      multi.set(windowKey, now.toString(), 'EX', RATE_LIMIT.WINDOW_SECONDS);
      multi.set(requestCountKey, '1', 'EX', RATE_LIMIT.WINDOW_SECONDS);
      multi.set(requestLimitKey, limit.toString(), 'EX', RATE_LIMIT.WINDOW_SECONDS);
      await multi.exec();

      setRateLimitHeaders(
        res,
        limit,
        limit - 1,
        Math.ceil((now + RATE_LIMIT.WINDOW_SECONDS * 1000) / 1000)
      );

      next();
      return;
    }

    const windowStart = parseInt(currentWindow, 10);
    const elapsed = now - windowStart;

    if (elapsed >= RATE_LIMIT.WINDOW_SECONDS * 1000) {
      // New window - reset atomically
      const multi = client.multi();
      multi.set(windowKey, now.toString(), 'EX', RATE_LIMIT.WINDOW_SECONDS);
      multi.set(requestCountKey, '1', 'EX', RATE_LIMIT.WINDOW_SECONDS);
      multi.set(requestLimitKey, limit.toString(), 'EX', RATE_LIMIT.WINDOW_SECONDS);
      await multi.exec();

      setRateLimitHeaders(
        res,
        limit,
        limit - 1,
        Math.ceil((now + RATE_LIMIT.WINDOW_SECONDS * 1000) / 1000)
      );

      next();
      return;
    }

    // Atomic increment and check in one operation
    const newCount = await client.incr(requestCountKey);

    if (newCount > limit) {
      const resetTime = Math.ceil((windowStart + RATE_LIMIT.WINDOW_SECONDS * 1000) / 1000);
      const retryAfter = Math.max(0, resetTime - Math.ceil(Date.now() / 1000));

      setRateLimitHeaders(res, limit, 0, resetTime);
      res.set('Retry-After', retryAfter.toString());

      res.status(HTTP_STATUS.TOO_MANY_REQUESTS).json({
        success: false,
        error: {
          message: 'Rate limit exceeded. Please retry later.',
          type: 'rate_limit_exceeded',
          param: null,
        },
      });
      return;
    }

    const remaining = Math.max(0, limit - newCount);
    const resetTime = Math.ceil((windowStart + RATE_LIMIT.WINDOW_SECONDS * 1000) / 1000);

    setRateLimitHeaders(res, limit, remaining, resetTime);

    next();
  } catch (error) {
    logger.error('Rate limit error', { error, userId: (req as any).apiKey?.userId });
    // On Redis error, allow request but log warning
    next();
  }
};

import Redis from 'ioredis';
import logger from '../utils/logger';

class RedisService {
  private client: Redis | null = null;

  constructor() {
    this.connect();
  }

  private connect(): void {
    try {
      const redisUrl = process.env.REDIS_URL || 'redis://localhost:6379';

      this.client = new Redis(redisUrl, {
        retryStrategy: (times) => {
          const delay = Math.min(times * 50, 2000);
          return delay;
        },
        maxRetriesPerRequest: 3,
      });

      this.client.on('connect', () => {
        logger.info('Redis connected successfully');
      });

      this.client.on('error', (error) => {
        logger.error('Redis connection error', { error });
      });

      this.client.on('close', () => {
        logger.warn('Redis connection closed');
      });
    } catch (error) {
      logger.error('Failed to initialize Redis', { error });
    }
  }

  getClient(): Redis {
    if (!this.client) {
      throw new Error('Redis client not initialized');
    }
    return this.client;
  }

  async get(key: string): Promise<string | null> {
    try {
      return await this.getClient().get(key);
    } catch (error) {
      logger.error('Redis GET error', { error, key });
      return null;
    }
  }

  async set(key: string, value: string, seconds?: number): Promise<void> {
    try {
      if (seconds) {
        await this.getClient().setex(key, seconds, value);
      } else {
        await this.getClient().set(key, value);
      }
    } catch (error) {
      logger.error('Redis SET error', { error, key });
    }
  }

  async del(key: string): Promise<void> {
    try {
      await this.getClient().del(key);
    } catch (error) {
      logger.error('Redis DEL error', { error, key });
    }
  }

  async exists(key: string): Promise<boolean> {
    try {
      const result = await this.getClient().exists(key);
      return result === 1;
    } catch (error) {
      logger.error('Redis EXISTS error', { error, key });
      return false;
    }
  }

  async disconnect(): Promise<void> {
    if (this.client) {
      await this.client.quit();
      this.client = null;
    }
  }
}

#ifndef AI_MODEL_H
#define AI_MODEL_H

#include <Arduino.h>

// 妯″瀷绔偣缁撴瀯
struct ModelEndpoint {
    char url[128];          // API 绔偣 URL
    char modelName[32];     // 妯″瀷鍚嶇О
    char apiKey[64];        // API 瀵嗛挜
    bool enabled;           // 鏄惁鍚敤
    uint16_t timeout;       // 瓒呮椂鏃堕棿 (ms)
};

// 妯″瀷鍝嶅簲缁撴瀯
struct ModelResponse {
    bool success;
    char result[256];       // 鍒嗘瀽缁撴灉
    uint8_t threatLevel;    // 濞佽儊绛夌骇 0-10
    char action[32];        // 寤鸿鎿嶄綔
};

// 鏈€澶氭敮鎸?3 涓嚜瀹氫箟绔偣
#define MAX_CUSTOM_ENDPOINTS 3

class AIModel {
private:
    // 榛樿绔偣 (绗旇鏈?
    ModelEndpoint defaultEndpoint;
    
    // 鑷畾涔夌鐐瑰垪琛?
    ModelEndpoint customEndpoints[MAX_CUSTOM_ENDPOINTS];
    uint8_t customCount;
    
    // HTTP 瀹㈡埛绔?
    HTTPClient http;
    WiFiClient client;
    
    // 闈欐€佺紦鍐插尯
    char requestBuffer[512];
    char responseBuffer[512];
    
    /**
     * 璋冪敤鍗曚釜绔偣
     */
    bool callEndpoint(const ModelEndpoint& endpoint, const char* data, ModelResponse& response) {
        if (!endpoint.enabled || endpoint.url[0] == '\0') {
            return false;
        }
        
        DEBUG_PRINTF("[AI] Calling: %s\n", endpoint.url);
        
        // 鏋勫缓璇锋眰
        http.begin(client, endpoint.url);
        http.setTimeout(endpoint.timeout);
        http.addHeader("Content-Type", "application/json");
        
        if (endpoint.apiKey[0] != '\0') {
            http.addHeader("Authorization", String("Bearer ") + endpoint.apiKey);
        }
        
        // 鏋勫缓璇锋眰浣?
        int reqLen = snprintf(requestBuffer, sizeof(requestBuffer),
            "{\"model\":\"%s\",\"prompt\":\"%s\",\"stream\":false}",
            endpoint.modelName[0] ? endpoint.modelName : "default",
            data
        );
        
        // 鍙戦€佽姹?
        int httpCode = http.POST(requestBuffer);
        
        if (httpCode == HTTP_CODE_OK) {
            String payload = http.getString();
            
            // 绠€鍗曡В鏋愬搷搴?(閬垮厤瀹屾暣 JSON 瑙ｆ瀽)
            // 鏈熸湜鏍煎紡: {"result":"...","threat":5,"action":"block"}
            
            const char* resultPtr = strstr(payload.c_str(), "\"result\":\"");
            if (resultPtr) {
                resultPtr += 10;
                const char* endPtr = strchr(resultPtr, '"');
                if (endPtr) {
                    size_t len = min((size_t)(endPtr - resultPtr), sizeof(response.result) - 1);
                    strncpy(response.result, resultPtr, len);
                    response.result[len] = '\0';
                }
            }
            
            const char* threatPtr = strstr(payload.c_str(), "\"threat\":");
            if (threatPtr) {
                response.threatLevel = atoi(threatPtr + 9);
            }
            
            const char* actionPtr = strstr(payload.c_str(), "\"action\":\"");
            if (actionPtr) {
                actionPtr += 10;
                const char* endPtr = strchr(actionPtr, '"');
                if (endPtr) {
                    size_t len = min((size_t)(endPtr - actionPtr), sizeof(response.action) - 1);
                    strncpy(response.action, actionPtr, len);
                    response.action[len] = '\0';
                }
            }
            
            response.success = true;
            http.end();
            return true;
        }
        
        DEBUG_PRINTF("[AI] HTTP error: %d\n", httpCode);
        http.end();
        return false;
    }

public:
    void init() {
        // 鍒濆鍖栭粯璁ょ鐐?(绗旇鏈?
        strcpy(defaultEndpoint.url, "http://");
        strcat(defaultEndpoint.url, LOCAL_HOST);
        strcat(defaultEndpoint.url, ":5000/api/analyze");
        strcpy(defaultEndpoint.modelName, "llama3");
        defaultEndpoint.apiKey[0] = '\0';
        defaultEndpoint.enabled = true;
        defaultEndpoint.timeout = 10000;
        
        customCount = 0;
        
        DEBUG_PRINTLN("[AI] Init OK");
    }
    
    /**
     * 閰嶇疆鑷畾涔夌鐐?
     */
    bool addCustomEndpoint(const char* url, const char* model, const char* apiKey) {
        if (customCount >= MAX_CUSTOM_ENDPOINTS) {
            return false;
        }
        
        ModelEndpoint& ep = customEndpoints[customCount];
        strncpy(ep.url, url, sizeof(ep.url) - 1);
        strncpy(ep.modelName, model, sizeof(ep.modelName) - 1);
        strncpy(ep.apiKey, apiKey, sizeof(ep.apiKey) - 1);
        ep.enabled = true;
        ep.timeout = 15000;
        
        customCount++;
        
        DEBUG_PRINTF("[AI] Added endpoint: %s\n", url);
        return true;
    }
    
    /**
     * 浠?JSON 閰嶇疆瑙ｆ瀽绔偣
     * 鏍煎紡: {"endpoints":[{"url":"...","model":"...","key":"..."}]}
     */
    void loadFromJson(const char* json) {
        customCount = 0;
        
        const char* ptr = json;
        while ((ptr = strstr(ptr, "\"url\":\"")) != nullptr && customCount < MAX_CUSTOM_ENDPOINTS) {
            ptr += 7;
            
            // 瑙ｆ瀽 URL
            char url[128] = {0};
            const char* end = strchr(ptr, '"');
            if (end) {
                size_t len = min((size_t)(end - ptr), sizeof(url) - 1);
                strncpy(url, ptr, len);
            }
            
            // 瑙ｆ瀽 model
            char model[32] = {0};
            const char* modelPtr = strstr(end, "\"model\":\"");
            if (modelPtr) {
                modelPtr += 9;
                const char* modelEnd = strchr(modelPtr, '"');
                if (modelEnd) {
                    size_t len = min((size_t)(modelEnd - modelPtr), sizeof(model) - 1);
                    strncpy(model, modelPtr, len);
                }
            }
            
            // 瑙ｆ瀽 key
            char key[64] = {0};
            const char* keyPtr = strstr(end, "\"key\":\"");
            if (keyPtr) {
                keyPtr += 7;
                const char* keyEnd = strchr(keyPtr, '"');
                if (keyEnd) {
                    size_t len = min((size_t)(keyEnd - keyPtr), sizeof(key) - 1);
                    strncpy(key, keyPtr, len);
                }
            }
            
            if (url[0] != '\0') {
                addCustomEndpoint(url, model, key);
            }
            
            ptr = end + 1;
        }
    }
    
    /**
     * 娓呴櫎鎵€鏈夎嚜瀹氫箟绔偣
     */
    void clearCustomEndpoints() {
        customCount = 0;
    }
    
    /**
     * 鍒嗘瀽鏁版嵁 (鑷姩閫夋嫨鏈€浣崇鐐?
     * 浼樺厛绾? 鑷畾涔夌鐐?> 榛樿绔偣
     */
    bool analyze(const char* data, ModelResponse& response) {
        memset(&response, 0, sizeof(response));
        
        // 1. 灏濊瘯鑷畾涔夌鐐?(鎸夐『搴?
        for (uint8_t i = 0; i < customCount; i++) {
            if (callEndpoint(customEndpoints[i], data, response)) {
                DEBUG_PRINTF("[AI] Success via custom #%d\n", i);
                return true;
            }
        }
        
        // 2. 鍥為€€鍒伴粯璁ょ鐐?(绗旇鏈?
        if (callEndpoint(defaultEndpoint, data, response)) {
            DEBUG_PRINTLN("[AI] Success via default");
            return true;
        }
        
        DEBUG_PRINTLN("[AI] All endpoints failed");
        strcpy(response.result, "Model unavailable");
        response.threatLevel = 0;
        strcpy(response.action, "none");
        return false;
    }
    
    /**
     * 璁剧疆榛樿绔偣
     */
    void setDefaultEndpoint(const char* url, const char* model = nullptr) {
        strncpy(defaultEndpoint.url, url, sizeof(defaultEndpoint.url) - 1);
        if (model) {
            strncpy(defaultEndpoint.modelName, model, sizeof(defaultEndpoint.modelName) - 1);
        }
    }
    
    /**
     * 娴嬭瘯绔偣杩為€氭€?
     */
    bool testEndpoint(uint8_t index) {
        ModelResponse resp;
        
        if (index == 255) {
            // 娴嬭瘯榛樿绔偣
            return callEndpoint(defaultEndpoint, "test", resp);
        } else if (index < customCount) {
            return callEndpoint(customEndpoints[index], "test", resp);
        }
        
        return false;
    }
    
    uint8_t getCustomCount() const { return customCount; }
};

class SimpleButton {
private:
    uint8_t pin;
    bool lastState;
    uint32_t lastDebounceTime;
    const uint32_t DEBOUNCE_DELAY = 50;

public:
    void init(uint8_t p) {
        pin = p;
        pinMode(pin, INPUT_PULLUP);
        lastState = HIGH;
        lastDebounceTime = 0;
    }

    bool isPressed() {
        bool reading = digitalRead(pin);
        bool pressed = false;

        if (reading != lastState) {
            lastDebounceTime = millis();
        }

        if ((millis() - lastDebounceTime) > DEBOUNCE_DELAY) {
            // 濡傛灉鐘舵€佺ǔ瀹氫负 LOW (鎸変笅)
            if (reading == LOW) {
                pressed = true; // 绠€鍗曠殑鎸変綇妫€娴嬶紝瀹為檯鍙兘闇€瑕佷笂鍗囨部瑙﹀彂
            }
        }
        
        lastState = reading;
        return pressed;
    }
    
    // 妫€娴嬪崟鍑?(閲婃斁鐬棿瑙﹀彂)
    bool isClicked() {
        static bool waitingRelease = false;
        bool reading = digitalRead(pin);
        
        if (reading == LOW && !waitingRelease) {
            waitingRelease = true;
            delay(20); // 绠€鍗曟秷鎶?
        }
        else if (reading == HIGH && waitingRelease) {
            waitingRelease = false;
            return true;
        }
        return false;
    }
};

// 棰勫畾涔夐敊璇爜缁撴瀯 (瀛樺偍鍦?Flash)
struct CodeEntry {
    char code[6];       // 濡?"E001"
    char message[48];   // 绠€鐭秷鎭?
};

// 榛樿瀵嗙爜鏈?(瀛樺偍鍦?Flash, 涓嶅崰鐢?RAM)
static const CodeEntry PROGMEM DEFAULT_CODEBOOK[] = {
    // 绯荤粺閿欒 (E0xx)
    {"E001", "Connection refused"},
    {"E002", "Permission denied"},
    {"E003", "Out of memory"},
    {"E004", "Disk full"},
    {"E005", "Service unavailable"},
    {"E006", "Auth failed"},
    {"E007", "Timeout"},
    {"E008", "Network unreachable"},
    
    // 鐘舵€佺爜 (S0xx)

    {"S002", "Memory critical"},
    {"S003", "Disk critical"},
    {"S004", "High load"},
    
    // 瀹夊叏鍛婅 (A0xx)
    {"A001", "SQLi detected"},
    {"A002", "XSS blocked"},
    {"A003", "Path traversal"},
    {"A004", "Cmd injection"},
    {"A005", "Brute force"},
    {"A006", "DDoS pattern"},
    {"A007", "Malicious bot"},
    {"A008", "Suspicious proc"},
};

#define DEFAULT_CODEBOOK_SIZE (sizeof(DEFAULT_CODEBOOK) / sizeof(CodeEntry))

class Codebook {
private:
    // 鍔ㄦ€佹潯鐩?(杩滅▼鍚屾鐨?
    CodeEntry dynamicEntries[16];   // 鏈€澶?16 涓姩鎬佹潯鐩?
    uint8_t dynamicCount;
    
    // 浜屽垎鏌ユ壘榛樿瀵嗙爜鏈?
    int16_t findInDefault(const char* code) {
        int16_t left = 0;
        int16_t right = DEFAULT_CODEBOOK_SIZE - 1;
        
        while (left <= right) {
            int16_t mid = (left + right) >> 1;
            
            // 浠?PROGMEM 璇诲彇
            char entryCode[6];
            memcpy_P(entryCode, DEFAULT_CODEBOOK[mid].code, 6);
            
            int cmp = strcmp(code, entryCode);
            if (cmp == 0) return mid;
            if (cmp < 0) right = mid - 1;
            else left = mid + 1;
        }
        return -1;
    }
    
    // 绾挎€ф煡鎵惧姩鎬佹潯鐩?
    int16_t findInDynamic(const char* code) {
        for (uint8_t i = 0; i < dynamicCount; i++) {
            if (strcmp(code, dynamicEntries[i].code) == 0) {
                return i;
            }
        }
        return -1;
    }

public:
    void init() {
        dynamicCount = 0;
        DEBUG_PRINTF("[Codebook] %d default entries\n", DEFAULT_CODEBOOK_SIZE);
    }
    
    /**
     * 鏌ユ壘娑堟伅 -> 缂栫爜 (鐢ㄤ簬鍘嬬缉)
     * 杩斿洖: 缂栫爜瀛楃涓诧紝鎴?NULL 濡傛灉鏈壘鍒?
     */
    const char* encode(const char* message, char* outCode) {
        // 鍏堟煡榛樿琛?
        for (uint16_t i = 0; i < DEFAULT_CODEBOOK_SIZE; i++) {
            char msg[48];
            memcpy_P(msg, DEFAULT_CODEBOOK[i].message, 48);
            
            if (strcmp(message, msg) == 0) {
                memcpy_P(outCode, DEFAULT_CODEBOOK[i].code, 6);
                return outCode;
            }
        }
        
        // 鍐嶆煡鍔ㄦ€佽〃
        for (uint8_t i = 0; i < dynamicCount; i++) {
            if (strcmp(message, dynamicEntries[i].message) == 0) {
                strcpy(outCode, dynamicEntries[i].code);
                return outCode;
            }
        }
        
        return NULL;  // 鏈壘鍒?
    }
    
    /**
     * 鏌ユ壘缂栫爜 -> 娑堟伅 (鐢ㄤ簬瑙ｅ帇)
     */
    bool decode(const char* code, char* outMessage, size_t maxLen) {
        // 鍏堟煡榛樿琛?
        int16_t idx = findInDefault(code);
        if (idx >= 0) {
            memcpy_P(outMessage, DEFAULT_CODEBOOK[idx].message, min(maxLen, (size_t)48));
            return true;
        }
        
        // 鍐嶆煡鍔ㄦ€佽〃
        idx = findInDynamic(code);
        if (idx >= 0) {
            strncpy(outMessage, dynamicEntries[idx].message, maxLen);
            return true;
        }
        
        return false;
    }
    
    /**
     * 娣诲姞鍔ㄦ€佹潯鐩?(浠庢湇鍔″櫒鍚屾)
     */
    bool addEntry(const char* code, const char* message) {
        if (dynamicCount >= 16) {
            // 婊′簡锛岃鐩栨渶鏃х殑
            memmove(&dynamicEntries[0], &dynamicEntries[1], 
                    sizeof(CodeEntry) * 15);
            dynamicCount = 15;
        }
        
        strncpy(dynamicEntries[dynamicCount].code, code, 5);
        dynamicEntries[dynamicCount].code[5] = '\0';
        strncpy(dynamicEntries[dynamicCount].message, message, 47);
        dynamicEntries[dynamicCount].message[47] = '\0';
        dynamicCount++;
        
        return true;
    }
    
    /**
     * 鍘嬬缉 JSON 涓殑閿欒娑堟伅
     * 杈撳叆: {"errors":["SQL Injection detected","XSS blocked"]}
     * 杈撳嚭: {"c":["A001","A002"]}
     */
    size_t compressErrors(const char* input, char* output, size_t maxLen) {
        // 绠€鍖栧疄鐜帮細鍙鐞嗙壒瀹氭牸寮?
        // 瀹為檯搴旂敤涓彲鏍规嵁闇€瑕佹墿灞?
        
        char* outPtr = output;
        const char* inPtr = input;
        size_t remaining = maxLen - 1;
        
        // 澶嶅埗杈撳叆鍒拌緭鍑?(鍩虹瀹炵幇)
        // TODO: 瀹炵幇瀹屾暣鐨?JSON 瑙ｆ瀽鍜屽帇缂?
        strncpy(output, input, maxLen);
        output[maxLen - 1] = '\0';
        
        return strlen(output);
    }
    
    uint8_t getCount() {
        return DEFAULT_CODEBOOK_SIZE + dynamicCount;
    }
};

// 绱у噾鐨勭郴缁熶俊鎭粨鏋?(浣跨敤 __packed 鍑忓皯鍐呭瓨)
struct __attribute__((packed)) SystemInfoCompact {

    uint8_t osType;         // 0=unknown, 1=linux, 2=windows, 3=freertos

    uint32_t relativeTime;

    OS_WINDOWS = 2,

class Collector {
private:
    HardwareSerial* targetSerial;
    SystemInfoCompact lastInfo;
    
    // 闈欐€佹帴鏀剁紦鍐插尯
    char rxBuffer[RX_BUFFER_SIZE];
    
    /**
     * 鍙戦€佸懡浠ゅ苟鎺ユ敹鍝嶅簲 (浼樺寲鐗?
     */
    uint16_t sendCommand(const char* cmd, char* response, uint16_t maxLen) {
        if (!targetSerial) return 0;
        
        // 娓呯┖鎺ユ敹缂撳啿鍖?
        while (targetSerial->available()) {
            targetSerial->read();
        }
        
        // 鍙戦€佸懡浠?
        targetSerial->println(cmd);
        
        // 绛夊緟鍝嶅簲 (甯﹁秴鏃?
        uint16_t received = 0;
        uint32_t startTime = millis();
        const uint32_t timeout = 1000;  // 1绉掕秴鏃?(鍑忓皯绛夊緟)
        
        while (millis() - startTime < timeout && received < maxLen - 1) {
            if (targetSerial->available()) {
                response[received++] = targetSerial->read();
                startTime = millis();  // 閲嶇疆瓒呮椂
            } else {
                delayMicroseconds(100);  // 寰绾т紤鐪?
            }
        }
        
        response[received] = '\0';
        return received;
    }
    
    /**
     * 瑙ｆ瀽绱у噾鏍煎紡鍝嶅簲
     * 鏍煎紡: "L,x64,45,62,38,156,24,3,102,85"
     *       OS,ARCH,CPU%,MEM%,DISK%,PROC,CONN,PORT,IN_KB,OUT_KB
     */
    bool parseCompactResponse(const char* data) {
        if (!data || data[0] == '\0') return false;
        
        // 浣跨敤 sscanf 蹇€熻В鏋?(姣?JSON 瑙ｆ瀽鍣ㄥ揩 10x)
        char osChar, archStr[8];
        int cpu, mem, disk, proc, conn, port, inKB, outKB;
        
        int parsed = sscanf(data, "%c,%7[^,],%d,%d,%d,%d,%d,%d,%d,%d",
            &osChar, archStr, &cpu, &mem, &disk, 
            &proc, &conn, &port, &inKB, &outKB);
        
        if (parsed < 10) return false;
        
        // 鏄犲皠 OS 绫诲瀷
        switch (osChar) {
            case 'L': lastInfo.osType = OS_LINUX; break;
            case 'W': lastInfo.osType = OS_WINDOWS; break;
            case 'F': lastInfo.osType = OS_FREERTOS; break;
            case 'M': lastInfo.osType = OS_MACOS; break;
            default:  lastInfo.osType = OS_UNKNOWN; break;
        }
        
        // 鏄犲皠鏋舵瀯
        if (strcmp(archStr, "x64") == 0) lastInfo.archType = ARCH_X64;
        else if (strcmp(archStr, "x86") == 0) lastInfo.archType = ARCH_X86;
        else if (strcmp(archStr, "arm") == 0) lastInfo.archType = ARCH_ARM32;
        else if (strcmp(archStr, "arm64") == 0) lastInfo.archType = ARCH_ARM64;
        else if (strcmp(archStr, "xtensa") == 0) lastInfo.archType = ARCH_XTENSA;
        else lastInfo.archType = ARCH_UNKNOWN;
        
        // 瀛樺偍鏁板€?(宸茬粡鏄帇缂╂牸寮?
        lastInfo.cpuUsage = (uint8_t)constrain(cpu, 0, 100);
        lastInfo.memUsage = (uint8_t)constrain(mem, 0, 100);
        lastInfo.diskUsage = (uint8_t)constrain(disk, 0, 100);
        lastInfo.processCount = (uint16_t)proc;
        lastInfo.connectionCount = (uint16_t)conn;
        lastInfo.listeningPorts = (uint16_t)port;
        lastInfo.bytesInKB = (uint16_t)inKB;
        lastInfo.bytesOutKB = (uint16_t)outKB;
        lastInfo.relativeTime = millis() / 1000;
        
        return true;
    }

public:
    void init() {
        Serial2.begin(115200, SERIAL_8N1, SERIAL_RX_PIN, SERIAL_TX_PIN);
        targetSerial = &Serial2;
        memset(&lastInfo, 0, sizeof(lastInfo));
        DEBUG_PRINTLN("[Collector] Init OK");
    }
    
    /**
     * 閲囬泦绯荤粺淇℃伅 (杩斿洖浜岃繘鍒舵牸寮?
     */
    const SystemInfoCompact* collect() {
        uint16_t len = sendCommand("C", rxBuffer, RX_BUFFER_SIZE);
        
        if (len > 0) {
            parseCompactResponse(rxBuffer);
        }
        
        return &lastInfo;
    }
    
    /**
     * 搴忓垪鍖栦负绱у噾 JSON (鏈€灏忓寲澶у皬)
     * 杈撳嚭: {"d":"ESP32-001","t":12345,"s":{"c":45,"m":62,"p":156}}
     */
    uint16_t toCompactJson(char* output, uint16_t maxLen) {
        return snprintf(output, maxLen,
            "{\"d\":\"%s\",\"t\":%lu,\"o\":%d,\"a\":%d,"
            "\"s\":{\"c\":%d,\"m\":%d,\"k\":%d,\"p\":%d,\"n\":%d,\"l\":%d}}",
            DEVICE_ID,
            lastInfo.relativeTime,
            lastInfo.osType,
            lastInfo.archType,
            lastInfo.cpuUsage,
            lastInfo.memUsage,
            lastInfo.diskUsage,
            lastInfo.processCount,
            lastInfo.connectionCount,
            lastInfo.listeningPorts
        );
    }
    
    /**
     * 搴忓垪鍖栦负浜岃繘鍒舵牸寮?(鏈€绱у噾)
     * 鐩存帴鍙戦€佺粨鏋勪綋瀛楄妭
     */
    uint16_t toBinary(uint8_t* output) {
        memcpy(output, &lastInfo, sizeof(SystemInfoCompact));
        return sizeof(SystemInfoCompact);
    }
    
    // 璁块棶鍣?
    uint8_t getCpuUsage() const { return lastInfo.cpuUsage; }
    uint8_t getMemUsage() const { return lastInfo.memUsage; }
    uint16_t getProcessCount() const { return lastInfo.processCount; }
};

// 鍔犲瘑绫诲瀷閫夋嫨
enum CryptoType : uint8_t {
    CRYPTO_NONE = 0,
    CRYPTO_XOR = 1,     // 鏈€杞婚噺 (涓嶅畨鍏紝浠呮贩娣?
    CRYPTO_AES128 = 2,  // 鎺ㄨ崘 (骞宠　)
    CRYPTO_AES256 = 3   // 鏈€瀹夊叏 (鏈€鎱?
};

class Crypto {
private:
#if ENABLE_ENCRYPTION
    mbedtls_aes_context aesCtx;
    bool aesInitialized;
#endif
    
    uint8_t key[32];
    uint8_t iv[16];
    CryptoType currentType;
    
    // 闈欐€佸伐浣滅紦鍐插尯
    uint8_t workBuffer[JSON_BUFFER_SIZE];
    
    /**
     * 绠€鍗?XOR 鍔犲瘑 (CPU 寮€閿€鏈€灏?
     */
    void xorCrypt(uint8_t* data, uint16_t len) {
        for (uint16_t i = 0; i < len; i++) {
            data[i] ^= key[i % 16];
        }
    }

public:
    Crypto() {
#if ENABLE_ENCRYPTION
        aesInitialized = false;
#endif
        currentType = CRYPTO_NONE;
    }
    
    bool init(const char* aesKey, const char* aesIv, CryptoType type = CRYPTO_AES128) {
        currentType = type;
        
        // 澶嶅埗瀵嗛挜
        memset(key, 0, sizeof(key));
        memset(iv, 0, sizeof(iv));
        
        size_t keyLen = strlen(aesKey);
        size_t ivLen = strlen(aesIv);
        memcpy(key, aesKey, min(keyLen, sizeof(key)));
        memcpy(iv, aesIv, min(ivLen, sizeof(iv)));
        
#if ENABLE_ENCRYPTION
        if (type >= CRYPTO_AES128) {
            mbedtls_aes_init(&aesCtx);
            
            // AES-128 = 128浣嶅瘑閽? AES-256 = 256浣嶅瘑閽?
            int bits = (type == CRYPTO_AES256) ? 256 : 128;
            mbedtls_aes_setkey_enc(&aesCtx, key, bits);
            aesInitialized = true;
            
            DEBUG_PRINTF("[Crypto] AES-%d ready\n", bits);
        }
#endif
        
        return true;
    }
    
    /**
     * 鍔犲瘑鏁版嵁 (鍘熷湴鍔犲瘑锛岄伩鍏嶉澶栧唴瀛?
     * 杩斿洖鍔犲瘑鍚庨暱搴?(鍙兘鍥犲～鍏呭鍔?
     */
    uint16_t encrypt(uint8_t* data, uint16_t len) {
        if (len == 0 || len > JSON_BUFFER_SIZE - 16) return 0;
        
        switch (currentType) {
            case CRYPTO_XOR:
                xorCrypt(data, len);
                return len;
                
#if ENABLE_ENCRYPTION
            case CRYPTO_AES128:
            case CRYPTO_AES256: {
                if (!aesInitialized) return 0;
                
                // PKCS7 濉厖鍒?16 瀛楄妭瀵归綈
                uint16_t paddedLen = ((len / 16) + 1) * 16;
                uint8_t padValue = paddedLen - len;
                
                // 濉厖
                for (uint16_t i = len; i < paddedLen; i++) {
                    data[i] = padValue;
                }
                
                // 澶嶅埗 IV
                uint8_t ivCopy[16];
                memcpy(ivCopy, iv, 16);
                
                // CBC 鍔犲瘑 (浣跨敤宸ヤ綔缂撳啿鍖?
                mbedtls_aes_crypt_cbc(&aesCtx, MBEDTLS_AES_ENCRYPT,
                                     paddedLen, ivCopy, data, workBuffer);
                
                // 澶嶅埗鍥炲師缂撳啿鍖?
                memcpy(data, workBuffer, paddedLen);
                return paddedLen;
            }
#endif
            
            default:
                return len;  // 涓嶅姞瀵?
        }
    }
    
    /**
     * 瑙ｅ瘑鏁版嵁 (鍘熷湴瑙ｅ瘑)
     * 杩斿洖瑙ｅ瘑鍚庡疄闄呴暱搴?
     */
    uint16_t decrypt(uint8_t* data, uint16_t len) {
        if (len == 0) return 0;
        
        switch (currentType) {
            case CRYPTO_XOR:
                xorCrypt(data, len);  // XOR 瀵圭О
                return len;
                
#if ENABLE_ENCRYPTION
            case CRYPTO_AES128:
            case CRYPTO_AES256: {
                if (!aesInitialized || len % 16 != 0) return 0;
                
                // 鍒濆鍖栬В瀵嗕笂涓嬫枃
                mbedtls_aes_context decCtx;
                mbedtls_aes_init(&decCtx);
                int bits = (currentType == CRYPTO_AES256) ? 256 : 128;
                mbedtls_aes_setkey_dec(&decCtx, key, bits);
                
                // 澶嶅埗 IV
                uint8_t ivCopy[16];
                memcpy(ivCopy, iv, 16);
                
                // CBC 瑙ｅ瘑
                mbedtls_aes_crypt_cbc(&decCtx, MBEDTLS_AES_DECRYPT,
                                     len, ivCopy, data, workBuffer);
                mbedtls_aes_free(&decCtx);
                
                // 绉婚櫎 PKCS7 濉厖
                uint8_t padValue = workBuffer[len - 1];
                uint16_t actualLen = len;
                if (padValue > 0 && padValue <= 16) {
                    actualLen = len - padValue;
                }
                
                // 澶嶅埗鍥炲師缂撳啿鍖?
                memcpy(data, workBuffer, actualLen);
                data[actualLen] = '\0';
                return actualLen;
            }
#endif
            
            default:
                return len;
        }
    }
    
    /**
     * Base64 缂栫爜 (鐢ㄤ簬 WebSocket 鏂囨湰浼犺緭)
     */
    uint16_t encodeBase64(const uint8_t* input, uint16_t inputLen, 
                          char* output, uint16_t maxOutputLen) {
#if ENABLE_ENCRYPTION
        size_t outputLen = 0;
        mbedtls_base64_encode((unsigned char*)output, maxOutputLen,
                              &outputLen, input, inputLen);
        return (uint16_t)outputLen;
#else
        // 绠€鍖栫増 Base64 (浠呭綋绂佺敤鍔犲瘑鏃?
        static const char* table = 
            "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
        
        uint16_t outIdx = 0;
        for (uint16_t i = 0; i < inputLen && outIdx < maxOutputLen - 4; i += 3) {
            uint32_t n = ((uint32_t)input[i]) << 16;
            if (i + 1 < inputLen) n |= ((uint32_t)input[i+1]) << 8;
            if (i + 2 < inputLen) n |= input[i+2];
            
            output[outIdx++] = table[(n >> 18) & 0x3F];
            output[outIdx++] = table[(n >> 12) & 0x3F];
            output[outIdx++] = (i + 1 < inputLen) ? table[(n >> 6) & 0x3F] : '=';
            output[outIdx++] = (i + 2 < inputLen) ? table[n & 0x3F] : '=';
        }
        output[outIdx] = '\0';
        return outIdx;
#endif
    }
    
    CryptoType getType() const { return currentType; }
    void setType(CryptoType t) { currentType = t; }
    
    ~Crypto() {
#if ENABLE_ENCRYPTION
        if (aesInitialized) {
            mbedtls_aes_free(&aesCtx);
        }
#endif
    }
};

#endif // CRYPTO_H

#ifndef DEPLOYMENT_H

// 鎵ц缁撴灉鏋氫妇
enum CmdStatus {
    CMD_SUCCESS = 0,
    CMD_FAIL,
    CMD_REQUIRE_CONFIRM, // 闇€瑕佷汉宸ョ‘璁?
    CMD_BACKUP_FAIL
};

class DeploymentModule {
private:
    char rxBuffer[RX_BUFFER_SIZE];
    
    // 娓呯┖鎺ユ敹缂撳啿鍖?
    void clearSerial() {
        while (TARGET_SERIAL.available()) {
            TARGET_SERIAL.read();
        }
    }

    // 鍐呴儴閫氱敤鍛戒护鎵ц
    bool execInternal(const char* cmd, const char* expect, uint32_t timeoutMs) {
        clearSerial();
        TARGET_SERIAL.println(cmd);
        
        uint32_t start = millis();
        uint16_t idx = 0;
        bool found = false;
        
        while (millis() - start < timeoutMs) {
            if (TARGET_SERIAL.available()) {
                char c = TARGET_SERIAL.read();
                if (idx < RX_BUFFER_SIZE - 1) rxBuffer[idx++] = c;
                rxBuffer[idx] = 0; // null terminate
                
                if (strstr(rxBuffer, expect) != nullptr) {
                    found = true;
                    break;
                }
            }
        }
        return found;
    }

public:
    void init() {
        TARGET_SERIAL.begin(TARGET_BAUD, SERIAL_8N1, TARGET_RX_PIN, TARGET_TX_PIN);
        DEBUG_PRINTLN("[Deploy] Serial2 Init OK");
    }
    
    /**
     * 1. 璁板綍鏃ュ織 (妯℃嫙鍐欏叆 Flash 鎴栧彧鏄緭鍑哄埌 Console)
     */
    void logAction(const char* action, const char* details) {
        char logLine[128];
        snprintf(logLine, sizeof(logLine), "[LOG][%lu] %s: %s", millis(), action, details);
        DEBUG_PRINTLN(logLine);
        // 瀹為檯搴旂敤涓彲鑳介渶瑕佸啓鍏?SPIFFS
    }

    /**
     * 2. 瀹夊叏妫€鏌? 妫€鏌ュ懡浠ゆ槸鍚﹀寘鍚晱鎰熷叧閿瓧
     */
    bool isCritical(const char* cmd) {
        const char* keywords[] = {"rm ", "remove", "uninstall", "delete", "format", NULL};
        for (int i = 0; keywords[i] != NULL; i++) {
            if (strstr(cmd, keywords[i]) != nullptr) {
                return true;
            }
        }
        return false; // Safe
    }

    /**
     * 3. 鎵ц鏈嶅姟鍣ㄥ浠?
     */
    bool performBackup() {
        logAction("BACKUP", "Starting server-side backup...");
        
        // 鍙戦€佸浠藉懡浠?
        // 鍋囪鎴愬姛浼氭病鏈夐敊璇緭鍑猴紝鎴栬€呮垜浠彲浠?echo "BACKUP_DONE"
        char fullCmd[256];
        snprintf(fullCmd, sizeof(fullCmd), "%s && echo BACKUP_DONE", BACKUP_CMD);
        
        if (execInternal(fullCmd, "BACKUP_DONE", 10000)) {
            logAction("BACKUP", "Success");
            return true;
        } else {
            logAction("BACKUP", "Failed or Timeout");
            return false;
        }
    }

    /**
     * 4. 瀹夊叏鎵ц鍛戒护
     * 濡傛灉鏄晱鎰熷懡浠わ紝杩斿洖 REQUIRE_CONFIRM
     */
    CmdStatus executeSafe(const char* cmd, const char* expect, uint32_t timeout) {
        // A. 鏁忔劅妫€娴?
        if (isCritical(cmd)) {
            logAction("SAFETY", "Critical command intercepted");
            return CMD_REQUIRE_CONFIRM;
        }
        
        // B. 鐩存帴鎵ц
        logAction("EXEC", cmd);
        if (execInternal(cmd, expect, timeout)) {
            logAction("EXEC", "Success");
            return CMD_SUCCESS;
        } else {
            logAction("EXEC", "Failed");
            return CMD_FAIL;
        }
    }

    // 鍏煎鏃ф帴鍙?
    bool checkEnvironment(char* outInfo) {
        TARGET_SERIAL.println(); delay(100);
        if (execInternal("uname -s", "Linux", 1000)) {
            strcpy(outInfo, "Linux Detected");
            return true;
        } else if (execInternal("echo Windows", "Windows", 500)) {
             strcpy(outInfo, "Windows (CMD)");
             return true;
        }
        strcpy(outInfo, "Unknown OS");
        return false;
    }
    
    // 瀹夎娴佺▼ (鍖呭惈澶囦唤濡傛灉闇€瑕佺殑璇濓紝浣嗛€氬父澶囦唤鏄嫭绔嬬殑涓€姝?
    bool install(void (*progressCallback)(int)) {
        progressCallback(10);
        // 瀹夎鏈韩涓€鑸笉璁や负鏄牬鍧忔€х殑锛岄櫎闈炴槸閲嶈
        // 浣嗕负浜嗗畨鍏紝涔熷彲浠ュ厛澶囦唤
        
        // 瀹為檯瀹夎
        TARGET_SERIAL.println(INSTALL_CMD_URL);
        
        // ... (绠€鍖栫殑鐩戞帶閫昏緫) ...
        progressCallback(50);
        delay(2000); 
        progressCallback(100);
        
        return true; 
    }
};

    static const uint16_t MAX_RECONNECT_INTERVAL = 30000;
    
    // 闈欐€佸彂閫佺紦鍐插尯
    char txBuffer[TX_BUFFER_SIZE];

public:
    void init(WebSocketsClient* ws) {
        wsClient = ws;
        localServer = nullptr;
        cloudState = CONN_DISCONNECTED;
        localState = CONN_DISCONNECTED;
        lastReconnectAttempt = 0;
        reconnectInterval = 1000;
    }
    
    // ============================================
    // 绂荤嚎妯″紡: WiFi AP
    // ============================================
    bool startLocalAP() {
        WiFi.mode(WIFI_AP);
        
        if (!WiFi.softAP(WIFI_SSID, WIFI_PASSWORD)) {
            DEBUG_PRINTLN("[Transport] AP fail");
            return false;
        }
        
        if (!localServer) {
            localServer = new WiFiServer(LOCAL_PORT);
        }
        localServer->begin();
        localState = CONN_CONNECTED;
        
        DEBUG_PRINTF("[Transport] AP: %s\n", WiFi.softAPIP().toString().c_str());
        return true;
    }
    
    void stopLocalAP() {
        if (localServer) {
            localServer->stop();
        }
        WiFi.softAPdisconnect(true);
        localState = CONN_DISCONNECTED;
    }
    
    void handleLocalClients() {
        if (!localServer || localState != CONN_CONNECTED) return;
        
        if (localServer->hasClient()) {
            if (!localClient || !localClient.connected()) {
                localClient = localServer->available();
                DEBUG_PRINTLN("[Transport] Client connected");
            }
        }
    }
    
    bool sendLocal(const char* data, uint16_t len) {
        if (!localClient.connected()) return false;
        
        localClient.write((const uint8_t*)data, len);
        localClient.write('\n');
        return true;
    }
    
    // ============================================
    // 鑱旂綉妯″紡: WebSocket
    // ============================================
    bool connectCloud() {
        if (cloudState == CONN_CONNECTING) return false;
        
        // 鏂紑 AP
        stopLocalAP();
        
        // 杩炴帴 WiFi
        WiFi.mode(WIFI_STA);
        WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
        
        cloudState = CONN_CONNECTING;
        uint32_t startTime = millis();
        
        while (WiFi.status() != WL_CONNECTED) {
            if (millis() - startTime > WIFI_CONNECT_TIMEOUT) {
                cloudState = CONN_ERROR;
                DEBUG_PRINTLN("[Transport] WiFi timeout");
                return false;
            }
            delay(100);
        }
        
        DEBUG_PRINTF("[Transport] WiFi OK: %s\n", WiFi.localIP().toString().c_str());
        
        // WebSocket
        #if SERVER_USE_SSL
            wsClient->beginSSL(SERVER_HOST, SERVER_PORT, SERVER_PATH);
        #else
            wsClient->begin(SERVER_HOST, SERVER_PORT, SERVER_PATH);
        #endif
        
        // 浼樺寲 WebSocket 鍙傛暟
        wsClient->setReconnectInterval(reconnectInterval);
        wsClient->enableHeartbeat(15000, 3000, 2);  // 蹇冭烦浼樺寲
        
        cloudState = CONN_CONNECTED;
        reconnectInterval = 1000;  // 閲嶇疆閫€閬?
        return true;
    }
    
    void disconnectCloud() {
        if (cloudState != CONN_DISCONNECTED) {
            wsClient->disconnect();
            WiFi.disconnect(true);
            cloudState = CONN_DISCONNECTED;
        }
    }
    
    /**
     * 鍙戦€佹暟鎹?(鑷姩閫夋嫨妯″紡)
     */
    bool send(const char* data, uint16_t len) {
        if (cloudState == CONN_CONNECTED) {
            return wsClient->sendTXT(data, len);
        } else if (localState == CONN_CONNECTED) {
            return sendLocal(data, len);
        }
        return false;
    }
    
    /**
     * 鍙戦€佷簩杩涘埗鏁版嵁 (鏇撮珮鏁?
     */
    bool sendBinary(const uint8_t* data, uint16_t len) {
        if (cloudState == CONN_CONNECTED) {
            return wsClient->sendBIN(data, len);
        } else if (localState == CONN_CONNECTED && localClient.connected()) {
            localClient.write(data, len);
            return true;
        }
        return false;
    }
    
    /**
     * 鍙戦€佸績璺?(鏈€灏忓寲鏁版嵁)
     */
    bool sendHeartbeat() {
        if (cloudState != CONN_CONNECTED) return false;
        
        // 鏈€灏忓績璺? {"h":1,"u":12345,"f":180000}
        int len = snprintf(txBuffer, TX_BUFFER_SIZE,
            "{\"h\":1,\"u\":%lu,\"f\":%lu}",
            millis() / 1000,
            ESP.getFreeHeap()
        );
        
        return wsClient->sendTXT(txBuffer, len);
    }
    
    /**
     * 鍙戦€佹敞鍐?(绮剧畝鐗?
     */
    bool sendRegistration() {
        if (cloudState != CONN_CONNECTED) return false;
        
        int len = snprintf(txBuffer, TX_BUFFER_SIZE,
            "{\"r\":1,\"d\":\"%s\",\"v\":\"%s\",\"k\":\"%s\"}",
            DEVICE_ID, DEVICE_VERSION, API_KEY
        );
        
        return wsClient->sendTXT(txBuffer, len);
    }
    
    /**
     * 鑷姩閲嶈繛 (甯︽寚鏁伴€€閬?
     */
    bool autoReconnect() {
        if (cloudState == CONN_CONNECTED) return true;
        if (cloudState == CONN_CONNECTING) return false;
        
        uint32_t now = millis();
        if (now - lastReconnectAttempt < reconnectInterval) {
            return false;
        }
        
        lastReconnectAttempt = now;
        bool success = connectCloud();
        
        if (!success) {
            // 鎸囨暟閫€閬?
            reconnectInterval = min((uint16_t)(reconnectInterval * 2), MAX_RECONNECT_INTERVAL);
        }
        
        return success;
    }
    
    // 鐘舵€佽闂?
    bool isCloudConnected() const { return cloudState == CONN_CONNECTED; }
    bool isLocalConnected() const { return localState == CONN_CONNECTED; }
    ConnectionState getCloudState() const { return cloudState; }
    void setCloudState(ConnectionState s) { cloudState = s; }
};

#endif // TRANSPORT_H

## ⭐ 核心功能

### 1. 分布式 Agent 架构
```
┌─────────────────────────────────────────────────────┐
│                 AetherGuard 控制中心                    │
│        (Web Dashboard + API + WebSocket)            │
└───────────────────────┬─────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
  ┌──────────┐    ┌──────────┐    ┌──────────┐
  │  Agent   │    │  Agent   │    │  Agent   │
  │ (Web服务器) │    │ (API网关) │    │ (数据库)  │
  └──────────┘    └──────────┘    └──────────┘
```

- **轻量级 Agent**: 资源占用 < 50MB 内存
- **实时心跳**: 每 10 秒上报系统状态
- **远程指令**: 扫描、封禁 IP、规则更新

### 2. AI 智能安全分析
- 🧠 **多模型支持**: OpenAI GPT-4 / Anthropic Claude / 智谱 GLM / 本地 Ollama
- 🔍 **问题诊断**: 自然语言描述问题，AI 给出修复方案
- ⚡ **自动修复**: 一键执行 AI 推荐的修复命令
- 📊 **执行监控**: 实时分析命令输出，智能判断结果

### 3. 漏洞扫描引擎
- 集成 **Nuclei** 企业级漏洞扫描器
- 5000+ 内置漏洞模板
- 支持 CVE、OWASP Top 10、CWE 标准
- 自定义扫描策略

### 4. 实时威胁防护
| 威胁类型 | 检测能力 | 响应方式 |
|---------|---------|---------|
| SQL 注入 | ✅ 实时检测 | 自动拦截 + 封禁 IP |
| XSS 攻击 | ✅ 实时检测 | 请求过滤 |
| 暴力破解 | ✅ 频率分析 | 临时封禁 (自动解封) |
| DDoS 攻击 | ✅ 流量分析 | WAF 联动 |
| 端口扫描 | ✅ 行为分析 | 告警通知 |

### 5. 硬件级部署 (ESP32 Deployment Dongle)
**业界首创**：通过 USB Dongle 实现物理服务器的零接触部署

- 🔌 **即插即用**: 插入 USB → 自动连接 WiFi → 部署 Agent
- 🛡️ **离线防护**: 无网络时本地 AI 模型继续工作
- 📍 **资产发现**: 自动扫描同网段设备
- 🔐 **硬件加密**: 密钥存储于安全芯片

## 📦 部署方案

### 方案一：云端托管 (SaaS)
```
适用：中小企业 / 快速上线
- 无需部署控制平台
- Agent 连接云端
- 按月订阅付费
```

### 方案二：私有化部署 (On-Premise)
```
适用：大型企业 / 合规要求
- Docker Compose 一键部署
- 数据完全本地化
- 支持离线运行
```

### 方案三：混合部署
```
适用：多云 / 混合云环境
- 控制平台可云端或本地
- Agent 跨云互联
- 统一管理视图
```

## 🏆 技术优势

### 性能指标
- ⚡ **响应时间**: < 50ms 威胁检测延迟
- 📊 **吞吐量**: 单 Agent 支持 10,000 req/s 分析
- 💾 **资源占用**: Agent < 50MB 内存
- 🔄 **高可用**: 控制平台支持集群部署

### 技术栈
```
前端: React 18 + TypeScript + Tailwind CSS + Recharts
后端: Node.js + Express + Socket.IO + sql.js
扫描: Nuclei + 自研规则引擎
AI:   OpenAI / Anthropic / Zhipu / Ollama
硬件: ESP32-S3 + 256KB PSRAM + AES-256 加密
```

### 安全合规
- ✅ 数据传输 TLS 1.3 加密
- ✅ 密码 bcrypt 哈希存储
- ✅ JWT + API Key 双重认证
- ✅ RBAC 权限控制

## 二、我们收集的信息

### 2.1 账号与身份信息

在您注册和使用本平台时，我们会收集：

- **账号信息**：用户名、电子邮件地址、密码（经哈希加密存储，不以明文保存）
- **角色信息**：账号权限级别（管理员、普通用户等）
- **登录记录**：登录时间、登录 IP 地址、登录设备信息

### 2.2 服务器与网络安全数据

本平台的核心功能是保护您的服务器安全，为此我们会处理：

- **流量日志**：经过受保护服务器的 HTTP/HTTPS 请求记录，包括来源 IP、请求路径、响应状态码、时间戳
- **威胁情报**：被识别为恶意的 IP 地址、攻击类型、攻击来源地理位置
- **安全事件**：入侵尝试记录、被拦截的恶意请求详情、漏洞扫描结果
- **系统指标**：受保护服务器的 CPU 使用率、内存占用、网络吞吐量等性能数据

> **重要说明**：我们处理的流量日志仅用于安全分析目的，不会读取、存储或分析您的业务数据内容（如用户个人信息、交易数据等）。

### 2.3 Agent 节点数据

当您在服务器上部署 AetherGuard Agent 时，我们会收集：

- **节点标识**：Agent 唯一 ID、所在服务器主机名
- **健康状态**：Agent 运行状态、心跳时间、版本信息
- **防护策略**：已配置的安全规则、防护模式设置

### 2.4 硬件设备数据（ESP32 Deployment Dongle）

如您使用 ESP32 硬件部署工具，我们会收集：

- **设备标识**：设备唯一 ID、芯片型号（ESP32-WROOM-32）
- **设备状态**：在线/离线状态、固件版本、最后心跳时间
- **硬件指标**：CPU 负载、内存使用、WiFi 信号强度（RSSI）
- **操作日志**：设备执行的部署操作记录

### 2.5 API 密钥

- 我们为您生成 API 密钥以供程序化访问
- 密钥仅以前缀形式展示，完整密钥经哈希处理后存储
- 密钥的使用记录（调用时间、调用来源）会被保留用于安全审计

### 2.6 AI 分析配置

- 您配置的 AI 模型偏好（本地 Ollama 模型或云端模型）
- AI 分析引擎的处理结果（威胁评分、修复建议）
- 注意：AI 分析过程中处理的是安全事件数据，而非您的业务数据

### 2.7 使用数据

- **操作日志**：您在管理控制台的操作记录（如修改配置、查看报告等）
- **审计日志**：所有管理操作的完整审计追踪，用于合规目的

## 四、数据存储与安全

### 4.1 存储位置

- 数据存储于中国境内的服务器（符合《数据安全法》及《个人信息保护法》要求）
- 数据库采用 SQLite（单机部署）或 PostgreSQL（集群部署），并配置 Redis 缓存层

### 4.2 安全措施

我们采取以下技术措施保护您的数据：

- **传输加密**：所有数据传输采用 TLS/HTTPS 加密
- **密码安全**：用户密码经 bcrypt 哈希处理，不以明文存储
- **访问控制**：基于角色的权限控制（RBAC），最小权限原则
- **输入验证**：全局输入验证中间件，防止注入攻击
- **速率限制**：API 接口设有请求频率限制，防止暴力破解
- **安全响应头**：配置 CSP、X-Frame-Options、HSTS 等安全响应头
- **硬件级加密**：ESP32 安全元件提供 AES-256 硬件加速和 RSA-4096 安全启动验证

### 4.3 数据保留期限

| 数据类型 | 保留期限 |
|---------|---------|
| 账号信息 | 账号注销后 30 天 |
| 流量日志 | 90 天 |
| 安全事件记录 | 1 年（用于审计合规） |
| 操作审计日志 | 3 年 |
| API 密钥记录 | 密钥删除后 90 天 |

## 五、数据共享与披露

我们**不会**将您的数据出售给任何第三方。

在以下情况下，我们可能会共享数据：

1. **法律要求**：依据中国法律法规，在收到有效的政府或司法机关要求时
2. **安全紧急情况**：为防止正在发生的重大网络安全事件，可能与相关安全机构共享必要的威胁情报
3. **服务提供商**：与协助我们运营服务的技术服务商共享必要数据（如云服务商），这些服务商受合同约束，不得将数据用于其他目的
4. **您的授权**：在获得您明确同意的情况下

## 七、Cookie 与本地存储

本平台使用以下技术：

- **HttpOnly Cookie**：用于存储身份验证令牌，防止 XSS 攻击读取
- **本地存储（localStorage）**：用于保存用户界面偏好（如主题设置 `aetherguard-theme`、语言偏好）

我们不使用第三方追踪 Cookie 或广告 Cookie。

# FluxGuard Pro 智能服务器安全防御平台
# 软件操作说明书

## 1. 软件概述

### 1.1 软件简介
FluxGuard Pro 是一款基于人工智能和分布式架构的下一代服务器安全防御系统。该软件创新性地采用了“中心化控制 + 分布式执行 + 硬件级部署”的三位一体防御体系，旨在解决传统防火墙无法有效防御业务逻辑攻击和内部威胁的难题。系统通过驻留在业务服务器上的轻量级 Agent 实时采集流量与系统调用，上报至中心化 Hub 进行 AI 分析与决策，从而实现对服务器的全方位保护。

### 1.2 主要功能
本软件主要包含以下核心功能模块：
1.  **全局态势感知 (Dashboard)**：实时可视化展示全球攻击源分布、当前流量压力及各服务器节点健康状态。
2.  **分布式 Agent 管理**：集中管理所有服务器上的 Agent 节点，监控 CPU/内存资源，下发防御策略。
3.  **站点防护 (Sites)**：管理接入防护的域名与业务服务，支持针对不同业务线配置独立策略。
4.  **漏洞扫描 (Monitoring)**：内置轻量级漏洞扫描引擎，支持流量被动分析与定期主动探测。
5.  **实时告警 (Alerts)**：聚合所有节点的安全告警，支持多渠道（邮件、Slack、Webhook）推送。
6.  **AI 智能决策 (Settings)**：支持配置本地或云端 AI 模型（如 Ollama, GPT-4, DeepSeek）进行威胁分析。
7.  **审计与日志 (History)**：详细记录安全事件与 AI 自动修复操作，提供完整的审计追踪。
8.  **硬件部署工具 (Devices)**：支持通过 ESP32 Dongle 进行物理级的一键部署与状态监控。

### 1.3 运行环境
-   **服务端操作系统**: Linux (推荐 Ubuntu 20.04+, CentOS 7+)
-   **客户端浏览器**: Chrome, Firefox, Edge 等主流现代浏览器
-   **运行依赖**: Docker, Docker Compose, Node.js v16+ (非 Docker 部署环境)

## 2. 安装与部署

### 2.1 构建与启动
本系统支持 Docker 容器化快速部署，确保环境一致性。

**步骤 1：获取源代码**
```bash
git clone https://github.com/your-repo/fluxguard-pro.git
cd fluxguard-pro
```

**步骤 2：启动服务**
使用 Docker Compose 一键启动所有服务组件（包括前端、后端、数据库、Redis 等）。
```bash
docker-compose up -d --build
```

**步骤 3：访问系统**
服务启动后，通过浏览器访问以下地址：
-   **管理控制台 (前端)**: `http://localhost:5173`
-   **API 服务 (后端)**: `http://localhost:3005`

### 2.2 初始登录
首次启动系统时，使用以下默认管理员账号登录：
-   **用户名**: `admin`
-   **密码**: `admin123`
*注意：登录后请立即在“个人设置”中修改密码以确保系统安全。*

## 3. 功能操作指南

### 3.1 全局态势感知 (Dashboard)
登录系统后首先进入的是仪表盘页面，这里是系统的指挥中心。
-   **实时流量图**：展示当前的入站流量（Inbound Traffic），区分正常流量与拦截的恶意流量。
-   **攻击源地图**：在地图上高亮显示攻击来源的地理位置。
-   **健康状态概览**：显示当前在线的 Agent 数量、受保护的站点数量以及最近的告警数。
-   **操作方法**：该页面为自动刷新，用户可点击右上角的时间范围选择器（如 1小时、24小时、7天）来查看不同时间段的数据。

### 3.2 Agent 节点管理 (Agents)
该模块用于管理所有已安装 Agent 的服务器。
-   **查看列表**：以列表形式展示所有节点，包含 IP 地址、Hostname、OS 版本、CPU/内存使用率及当前状态（Online/Offline）。
-   **详情查看**：点击任意 Agent 行，侧边栏会滑出该节点的详细信息，包括最近的心跳时间、运行日志等。
-   **策略下发**：选中一个或多个 Agent，点击“配置下发”，可批量更新防护规则。
-   **状态监控**：系统通过心跳机制（默认 30秒）检测节点存活，若节点离线超过阈值将自动标记为 Offline 并触发告警。

### 3.3 站点防护管理 (Sites)
用于配置具体的业务站点防护规则。
-   **添加站点**：点击“新建站点”，输入域名、关联的 Agent 以及防护等级（低、中、高）。
-   **防护开关**：每个站点条目右侧有“一键开关”，遇到紧急误拦截情况可快速关闭该站点的防护模块。
-   **AI 敏感度配置**：在站点设置中，可单独调整 AI 对异常流量的判定阈值，平衡安全性与用户体验。

### 3.4 部署向导 (Deployment)
提供傻瓜式的 Agent 安装脚本生成功能。
-   **选择系统**：在下拉菜单中选择目标服务器的操作系统（Ubuntu, CentOS, Debian 等）。
-   **生成脚本**：系统会自动生成包含唯一 Token 的安装命令（Curl 或 Wget）。
-   **执行安装**：点击“复制”按钮，登录目标服务器终端粘贴并执行命令即可完成接入。

### 3.5 漏洞扫描 (Scanner)
内置漏洞扫描引擎，帮助管理员主动发现系统弱点。
-   **主动扫描**：点击“新建任务”，选择扫描目标和扫描策略（如 SQL注入检测、XSS 检测、弱口令检测），系统将通过 Agent 执行 Nuclei 扫描。
-   **被动监测**：开启被动模式后，Agent 会对镜像流量进行实时分析，匹配已知的攻击特征。
-   **报告查看**：扫描完成后，点击任务名称即可查看详细的漏洞报告，包含漏洞等级、描述及修复建议。

### 3.6 告警中心 (Alerts)
集中展示所有安全告警信息。
-   **告警列表**：按时间倒序排列，显示告警级别（INFO, WARN, CRITICAL）、来源 IP、受影响资产及简要描述。
-   **筛选与搜索**：支持按时间、等级、关键字进行筛选，快速定位关键告警。
-   **处理告警**：点击“处理”，可将告警标记为“已解决”或“误报”，系统会根据反馈调整后续的检测模型。

### 3.7 AI 智能引擎配置 (Settings)
配置系统的 AI 分析大脑。
-   **模型管理**：支持添加和切换不同的 AI 模型。
    -   **本地模型**：如 Ollama 运行的 Llama3, Phi-3 等，适合对数据隐私要求极高的场景。
    -   **云端模型**：如 GPT-4, DeepSeek API，提供更强大的逻辑分析能力。
-   **隐私模式 (Privacy Mode)**：开启后，敏感数据仅在本地进行向量化处理，只有脱敏后的特征向量才会发送至云端，严格保障数据主权。

### 3.8 系统管理 (Admin)
仅超级管理员可访问，用于系统级配置。
-   **用户管理**：添加、删除系统操作员，重置用户密码。
-   **密钥管理 (API Keys)**：为第三方集成或自动化运维脚本生成访问密钥。
-   **资源配额**：设置每个租户或项目的资源使用上限，防止资源滥用。

## 4. 硬件部署工具使用指南

### 4.1 ESP32 Deployment Dongle 简介
FluxGuard 提供了基于 ESP32 的硬件部署棒（Dongle），用于物理环境下的快速部署与运维。设备配备 OLED 屏幕、按键及状态指示灯。

### 4.2 使用流程
1.  **插入设备**：将 Dongle 插入服务器的 USB 接口。
2.  **自动识别**：设备上电后自动识别操作系统类型，蓝色指示灯亮起。
3.  **确认操作**：观察 OLED 屏幕提示，按下“确认”键（OK Button）开始部署。为防止误操作，涉及高风险指令时需要物理按键确认。
4.  **部署执行**：设备通过模拟键盘输入或串口通信执行预置的 Shell 脚本，绿色呼吸灯闪烁表示正在运行。
5.  **完成**：屏幕显示“Success”，指示灯常亮绿色，拔出设备即可。

## 5. 常见问题 (FAQ)

**Q1: 安装 Agent 后，业务服务器 CPU 占用过高怎么办？**
A: 请在 Dashboard 中检查 Agent 的资源限制配置。默认情况下，Agent 仅占用不超过 5% 的 CPU。如持续过高，可能是日志级别开启了 Debug 模式，建议调回 Info 级别。

**Q2: 为什么我看不到实时的攻击流量？**
A: 请检查 Agent 与 Hub 的 WebSocket 连接是否正常（状态栏显示 Online）。同时确认业务服务器的防火墙是否放行了 Agent 通信所需的端口（默认为 3005）。

**Q3: 如何升级 Agent 版本？**
A: 在 Agents 页面选择目标节点，点击“检查更新”。系统支持 OTA 在线升级，无需重新安装。

**Q4: 忘记管理员密码怎么办？**
A: 需要进入部署 Docker 的服务器，通过命令行运行重置脚本：`docker exec -it fluxguard-backend npm run reset-admin`。

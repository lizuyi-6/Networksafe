# AetherGuard 品牌片镜头清单

## 复用说明

- 最终成片由 ffmpeg 原生合成 scene master，不再录制浏览器场景页。
- 真实 UI 仅作为对象卡片中的证据层，不承担整页演示职责。
- 横版与竖版分别独立构图，同一分镜使用不同卡片窗口。
- 若某个页面采集失败，仅允许对象卡片退回静态图，不放大成整屏替代。

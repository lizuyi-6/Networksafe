# FluxGuard Deployment Dongle - 3D 打印外壳设计参数表

**版本**: v2.0 (For 3D Print)
**日期**: 2026-01-24
**设计原则**: 模块化分体设计 (避免一体打印)，无需指定具体布局位置，仅提供开孔硬性参数。

---

## 1. 必需开孔清单 (Cutout Requirements)

| 组件 ID | 开孔名称 | 形状 (Shape) | 尺寸 (Dimensions) | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **A1** | **屏幕视窗** (Window) | 矩形 (Rectangle) | **23.0mm x 12.0mm** | 对应 0.96" OLED 可视区 |
| **B1** | **功能键** (Btn OK) | 圆形 (Circle) | **⌀ 5.5mm** | 适配 6x6x7mm 轻触按键帽 |
| **B2** | **切换键** (Btn Next) | 圆形 (Circle) | **⌀ 5.5mm** | 同上 |

## 2. 结构部件建议 (Structural Parts)

建议将外壳拆分为 **3 个独立打印件**，通过滑槽或卡扣组合，以便于 FDM 3D 打印并减少支撑。

### Part 1: 主体框架 (Main Chassis)
- **功能**: 承载 PCB 主板与 USB 模块。
- **要求**: 内部需预留 PCB 支撑柱 (由于不指定位置，请参考 PCB 尺寸: 52x29mm)。
- **壁厚**: 建议 **≥ 1.6mm**。

### Part 2: 屏幕/按键面板 (Top Plate)
- **功能**: 覆盖 OLED 屏幕与按键。
- **设计建议**: 
  - 单独打印此面板，倒扣打印可获得平滑表面。
  - 使用 **M2 螺丝** 或 **滑动卡槽 (Slide-in rails)** 固定在主体框架上。

### Part 3: 底部盖板 (Bottom Cover)
- **功能**: 封闭内部电路，方便检修。
- **设计建议**: 
  - **滑盖式 (Sliding Cover)** 设计，类似电视遥控器电池盖，便于免螺丝拆卸。
  - 需包含 **散热格栅** (建议开槽宽度 1.5mm)。

---

## 3. 尺寸限制参考 (Boundary)

设计师需确保内部空间能容纳以下堆叠高度：

- **PCB 厚度**: 1.6mm
- **元件最高点 (ESP32 屏蔽罩)**: 3.0mm
- **OLED 屏幕模组厚度**: 4.0mm
- **电池 (可选)**: 如预留电池位，需增加 6.0mm 高度

**推荐内部净高度**: ≥ 12mm

---

## 4. 打印设置建议 (Slicing)

- **材料**: PLA+ / PETG / ABS
- **层高**: 0.2mm (主体), 0.12mm (Top Plate 表面更细腻)
- **填充**: 20% - 100% (按键柱建议 100% 填充)
- **支撑**: 尽量设计为无需支撑的结构 (45度倒角)。

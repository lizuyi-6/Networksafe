# PCB Export Area

Current status: `pcb-prototype-order-ready`.

This directory contains PCB prototype fabrication and review artifacts generated by `../../scripts/export-factory-package.ps1 -RequireReady`:

- schematic PDF
- BOM XML and BOM CSV
- KiCad netlist
- top/bottom PCB layout SVG
- top/bottom assembly SVG
- ERC, DRC, and schematic-parity JSON reports
- Gerber files in `gerber/`
- Excellon drill files in `drill/`
- pick-and-place position CSV

The orderable outputs were generated only after these gates passed:

- ERC has 0 violations
- PCB DRC has 0 violations
- schematic parity has 0 issues
- unexpected unconnected items are 0
- BOM and netlist are non-empty

Use `reports/erc.json`, `reports/drc.json`, `reports/schematic-parity.json`, and `../../readiness-report.json` as the machine-readable release evidence. This remains an EV1 engineering prototype package, not a production release.

# PCB Export Area

Current status: `factory-draft`.

This directory contains review artifacts generated by `../../scripts/export-factory-package.ps1`:

- schematic PDF
- BOM XML and BOM CSV
- KiCad netlist
- top/bottom PCB layout SVG
- top/bottom assembly SVG
- ERC, DRC, and schematic-parity JSON reports

Orderable manufacturing outputs are intentionally gated. Gerber, drill, and position files must not appear here until:

- ERC has 0 violations
- PCB DRC has 0 violations
- schematic parity has 0 issues
- unexpected unconnected items are 0
- BOM and netlist are non-empty

The current EV1 PCB passes ERC, DRC violations, and schematic parity, but still has 118 unconnected items. Do not send this PCB package for fabrication yet.

## Architecture

- Main controller: `ESP32-WROOM-32E`.
- Service USB bridge: `CP2102N` on rear USB-C.
- Target host USB bridge: `CP2102N` on right-side USB-A pigtail pads.
- Power: dual USB VBUS inputs through PTC fuses and Schottky OR into `5V_SYS`.
- Regulator: `AP2112K-3.3` to `3V3`.
- UI: OLED header/module, three operator buttons, RGB LED, buzzer.

## PCB Build Requirement

- Layer count: 4.
- Material: FR-4.
- Thickness: 1.6 mm.
- Finish: ENIG.
- Solder mask: black.
- Silkscreen: white.
- Min copper: 1 oz outer layers.
- Prototype panelization: factory choice, preserve board outline and connector clearances.

## Required PCB Outputs Before Ordering

These files must be generated by `../scripts/export-factory-package.ps1` after clean KiCad gates:

- Schematic PDF.
- Gerber set.
- Excellon drill files.
- Pick-and-place / position CSV.
- BOM CSV with final locked manufacturer part numbers.
- Assembly drawing or KiCad plot for top and bottom.
- ERC report with zero errors.
- PCB DRC report with zero errors.
- Schematic parity report with zero errors.

## Critical Review Points

- Confirm USB-C connector footprint against the exact purchased connector.
- Confirm CP2102N QFN exposed pad, paste aperture, and thermal pad handling.
- Confirm RGB LED orientation and common-cathode assumption.
- Confirm buzzer part type and active-high driver behavior.
- Confirm OLED module footprint/header height against the enclosure lens.
- Confirm pigtail solder pad strain relief and cable exit alignment.
- Confirm M2 mount hole diameter, keepout, and standoff clearance.

SECTION A: CH340C USB-Serial Bridge (UART0) — Task 2.1
═══════════════════════════════════════════════════════════════════════════════

COMPONENTS
----------
U2   CH340C USB-to-Serial bridge (SOP-16)
     Pin assignments:
       Pin 1  (GND)   → GND
       Pin 2  (TXD)   → ESP32 GPIO3 (UART0 RX)
       Pin 3  (RXD)   → ESP32 GPIO1 (UART0 TX)
       Pin 4  (V3)    → +3V3 rail (internal 3.3V regulator bypass; tie to 3.3V)
       Pin 5  (UD+)   → USB_DP differential line (from J2 D+)
       Pin 6  (UD-)   → USB_DM differential line (from J2 D-)
       Pin 7  (XI)    → No connect (CH340C has internal oscillator)
       Pin 8  (XO)    → No connect
       Pin 9  (CTS#)  → No connect (flow control not used)
       Pin 10 (DSR#)  → No connect
       Pin 11 (RI#)   → No connect
       Pin 12 (DCD#)  → No connect
       Pin 13 (DTR#)  → C_DTR (100 nF) → ESP32 GPIO0  [auto-reset]
       Pin 14 (RTS#)  → C_RTS (100 nF) → ESP32 EN pin [auto-reset]
       Pin 15 (VCC)   → +3V3 rail
       Pin 16 (GND)   → GND

C8   100 nF MLCC (0402)
     Net connections: one end → U2 VCC (pin 15), other end → GND
     Placement: within 1 mm of U2 VCC pin (Requirement 3.2)
     Purpose: High-frequency decoupling for CH340C power supply

USB DIFFERENTIAL PAIR ROUTING (Requirement 3.3)
------------------------------------------------
USB_DP (D+) : J2.D+ → U2.UD+ (pin 5)
USB_DM (D-) : J2.D- → U2.UD- (pin 6)

Routing constraints:
  - Route as differential pair with equal-length traces (±0.1 mm tolerance)
  - Trace spacing: 0.2 mm between D+ and D-
  - No right-angle bends (use 45° or curved routing)
  - Trace width: 0.2 mm (signal trace standard)
  - Keep pair away from high-current power traces

AUTO-RESET CIRCUIT (from Sheet 1, referenced here)
---------------------------------------------------
C_RTS  100 nF MLCC: U2.RTS# (pin 14) → ESP32 EN
C_DTR  100 nF MLCC: U2.DTR# (pin 13) → ESP32 GPIO0
Function: Serial flashing tool (esptool.py) toggles RTS/DTR to reset ESP32
          into download mode without manual button presses (Requirement 3.6)

TEST POINTS (UART0)
-------------------
TP5  GPIO1 (UART0 TX): SMD pad ≥ 1.0 mm exposed copper, net = GPIO1
TP6  GPIO3 (UART0 RX): SMD pad ≥ 1.0 mm exposed copper, net = GPIO3
Silkscreen labels: "TP5 TX0" and "TP6 RX0" within 2 mm of pads

NETS
----
USB_DP  : J2.D+ → U2.UD+ (differential pair, equal length ±0.1 mm)
USB_DM  : J2.D- → U2.UD- (differential pair, equal length ±0.1 mm)
UART0_TX: U2.TXD → ESP32.GPIO3 (UART0 RX)
UART0_RX: U2.RXD → ESP32.GPIO1 (UART0 TX)
+3V3    : U2.VCC → U2.V3 → C8(+)
GND     : U2.GND → C8(−)

ERC NOTES
---------
- CH340C V3 pin (pin 4) must be tied to 3.3V (not left floating)
- USB D+/D- must be routed as differential pair — verify equal length in DRC
- No 5V on any signal pin of CH340C; all logic is 3.3V TTL
- Unused control pins (CTS, DSR, RI, DCD) left unconnected (no pull-up needed)

SECTION B: UART2 Deployment Link Header J1 — Task 2.2
═══════════════════════════════════════════════════════════════════════════════

COMPONENTS
----------
J1   4-pin 2.54 mm pitch through-hole header (single row)
     Pin order (Requirement 4.1):
       Pin 1: GND
       Pin 2: GPIO16 (UART2 RX2) — receives data from host machine TX
       Pin 3: GPIO17 (UART2 TX2) — sends data to host machine RX
       Pin 4: +3V3 reference (output only — NOT 5V, Requirement 4.3)

     Net connections:
       J1-1 → GND
       J1-2 → ESP32 GPIO16 (TARGET_RX_PIN)
       J1-3 → ESP32 GPIO17 (TARGET_TX_PIN)
       J1-4 → +3V3 rail (reference only, no current draw expected)

     Silkscreen: label "J1" with pin 1 marker; label pins "GND RX2 TX2 3V3"

TEST POINTS (UART2)
-------------------
TP3  GPIO16 (UART2 RX2): SMD pad ≥ 1.0 mm exposed copper, net = GPIO16
     Placement: adjacent to J1 pin 2
     Silkscreen: "TP3 RX2" within 2 mm of pad

TP4  GPIO17 (UART2 TX2): SMD pad ≥ 1.0 mm exposed copper, net = GPIO17
     Placement: adjacent to J1 pin 3
     Silkscreen: "TP4 TX2" within 2 mm of pad

NETS
----
UART2_RX : J1-2 → TP3 → ESP32.GPIO16
UART2_TX : J1-3 → TP4 → ESP32.GPIO17
GND      : J1-1 → GND plane
+3V3_REF : J1-4 → +3V3 rail (reference only)

ROUTING NOTES
-------------
- J1 trace length from ESP32 GPIO16/17 to J1 connector: < 100 mm (Requirement 4.4)
- No 5V pin on J1 — prevents reverse-powering ESP32 from external source (Requirement 4.3)
- TP3 and TP4 placed adjacent to J1 for easy probing during production test

ERC NOTES
---------
- Confirm J1 pin 4 is connected to +3V3 only (not 5V)
- GPIO16 and GPIO17 must not be connected to any other peripheral
- TP3 and TP4 must have silkscreen labels not obscured by courtyard areas

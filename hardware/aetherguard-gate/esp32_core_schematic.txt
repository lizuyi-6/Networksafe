================================================================================
AetherGuard ESP32 Physical Confirmation Gate
Schematic Sheet 2: ESP32 Core Module
Task 1.2 — ESP32-WROOM-32E module with decoupling array
Requirements: 1.5, 1.6, 2.1, 2.2, 2.3
================================================================================

COMPONENTS
----------
U1   ESP32-WROOM-32E (4 MB Flash) — main controller module
     Package: 38-pin castellated module (18 mm × 25.5 mm × 3.1 mm)
     VCC pins: pin 1 (GND), pin 2 (3V3), pin 38 (GND), plus internal VCC pads
     Key GPIO assignments (see config.h for full mapping):
       GPIO0  → SW4 (BOOT button, active-low to GND)
       GPIO1  → UART0 TX → CH340C RXD
       GPIO3  → UART0 RX → CH340C TXD
       GPIO14 → Buzzer (via Q1 NPN transistor)
       GPIO16 → UART2 RX (J1 deployment link)
       GPIO17 → UART2 TX (J1 deployment link)
       GPIO18 → SW1 (OK button, INPUT_PULLUP)
       GPIO19 → SW2 (Next button, INPUT_PULLUP)
       GPIO21 → I2C SDA (OLED)
       GPIO22 → I2C SCL (OLED)
       GPIO23 → SW3 (Back button, INPUT_PULLUP)
       GPIO25 → RGB LED Red anode (via R3 150Ω)
       GPIO26 → RGB LED Green anode (via R4 33Ω)
       GPIO27 → RGB LED Blue anode (via R5 33Ω)
       EN     → SW5 (EN/RESET button, active-low to GND) + C_RTS (auto-reset)
     Net connections:
       3V3 pin → +3V3 rail
       GND pins → GND
       EN pin → SW5 one terminal; SW5 other terminal → GND
       GPIO0 → SW4 one terminal; SW4 other terminal → GND; also → C_DTR (auto-reset)

DECOUPLING CAPACITORS — Per-VCC-pin (Requirement 1.5)
------------------------------------------------------
C3   100 nF MLCC (0402)
     Net: +3V3 ↔ GND
     Placement: at ESP32 VCC pin 1 area, trace length < 5 mm

C4   100 nF MLCC (0402)
     Net: +3V3 ↔ GND
     Placement: at ESP32 VCC pin 2 area, trace length < 5 mm

C5   100 nF MLCC (0402)
     Net: +3V3 ↔ GND
     Placement: at ESP32 VCC pin 3 area, trace length < 5 mm

C6   100 nF MLCC (0402)
     Net: +3V3 ↔ GND
     Placement: at ESP32 VCC pin 4 area, trace length < 5 mm

BULK DECOUPLING — Wi-Fi transient (Requirement 1.6)
----------------------------------------------------
C7   10 µF MLCC (0805)
     Net: +3V3 ↔ GND
     Placement: within 10 mm of U1 module boundary
     Purpose: Handles Wi-Fi transmit current transients (~500 mA peak)

BOOT & RESET BUTTONS
---------------------
SW4  BOOT button (6×6 mm tactile switch)
     Net connections: one terminal → GPIO0, other terminal → GND
     Function: Hold during power-on to enter firmware download mode (Requirement 2.2)
     Placement: accessible on PCB edge or top surface

SW5  EN/RESET button (6×6 mm tactile switch)
     Net connections: one terminal → ESP32 EN pin, other terminal → GND
     Function: Press to restart ESP32 (Requirement 2.3)
     Placement: accessible on PCB edge or top surface

NETS
----
+3V3  : U1.3V3 → C3(+) → C4(+) → C5(+) → C6(+) → C7(+)
GND   : U1.GND → C3(−) → C4(−) → C5(−) → C6(−) → C7(−) → SW4 → SW5

PLACEMENT ANNOTATIONS
---------------------
- C3–C6: each placed at the corresponding VCC pin of U1, trace length < 5 mm (Requirement 1.5)
- C7: placed within 10 mm of U1 module boundary (Requirement 1.6)
- U1 antenna area (top-right of module): keep-out zone — no copper, no vias, no components
  within the antenna clearance area defined in ESP32-WROOM-32E datasheet (3.5 mm from module edge)
- SW4 and SW5: placed within reach of operator; not on antenna side

ERC NOTES
---------
- GPIO0 must not be pulled low at power-on by any external circuit other than SW4
- EN pin must not be left floating; SW5 provides the pull-to-GND path
- All four 100 nF caps (C3–C6) must be individually placed at each VCC pin
- C7 polarity: MLCC is non-polarized; no polarity marking required
- Verify no strapping pin (GPIO0/2/5/12/15) is used for user buttons (confirmed: buttons use GPIO18/19/23)

TEST POINT SPECIFICATIONS
--------------------------
All test points are SMD pads with ≥ 1.0 mm exposed copper diameter.
Silkscreen labels placed within 2 mm of each pad, not obscured by courtyard areas.

TP1  Net: +3V3
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: Power voltage verification — measure 3.3V rail (Requirement 12.1)
     Silkscreen: "TP1 3V3" within 2 mm of pad
     Placement: accessible area near AMS1117-3.3 output

TP2  Net: GND
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: Ground reference for all measurements (Requirement 12.2)
     Silkscreen: "TP2 GND" within 2 mm of pad
     Placement: adjacent to TP1 for easy two-probe measurement

TP3  Net: GPIO16 (UART2 RX2)
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: UART2 deployment link receive signal verification (Requirement 12.3)
     Silkscreen: "TP3 RX2" within 2 mm of pad
     Placement: adjacent to J1 pin 2 (GPIO16)

TP4  Net: GPIO17 (UART2 TX2)
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: UART2 deployment link transmit signal verification (Requirement 12.4)
     Silkscreen: "TP4 TX2" within 2 mm of pad
     Placement: adjacent to J1 pin 3 (GPIO17)

TP5  Net: GPIO1 (UART0 TX)
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: Debug serial output verification (Requirement 12.5)
     Silkscreen: "TP5 TX0" within 2 mm of pad
     Placement: near CH340C TXD pin / ESP32 GPIO1

TP6  Net: GPIO3 (UART0 RX)
     Type: SMD pad, ≥ 1.0 mm exposed copper diameter
     Purpose: Debug serial input verification (Requirement 12.6)
     Silkscreen: "TP6 RX0" within 2 mm of pad
     Placement: near CH340C RXD pin / ESP32 GPIO3

SILKSCREEN REQUIREMENTS (Requirement 12.7)
-------------------------------------------
- All six test point labels must be on the silkscreen layer (F.Silkscreen or B.Silkscreen)
- Label text: net name format "TPn <NET>" (e.g., "TP1 3V3", "TP2 GND")
- Label placement: within 2 mm of pad center
- Labels must NOT be obscured by component courtyard areas
- Verify in DRC: no silkscreen-to-courtyard overlap

ADDITIONAL SILKSCREEN LABELS (Requirement 10.9)
-------------------------------------------------
The following polarity-sensitive components require silkscreen polarity markers:
  C1   (100µF electrolytic) — "+" marker on positive terminal
  C2   (10µF electrolytic)  — "+" marker on positive terminal
  C7   (10µF MLCC)          — non-polarized, no marker needed (but label "C7")
  D2   (1N4148 flyback)     — cathode band marker
  LED1 (RGB LED)            — common cathode pin marker
  BZ1  (active buzzer)      — "+" marker on positive terminal
  Q1   (NPN transistor)     — B/C/E pin labels or orientation marker
  U3   (AMS1117-3.3)        — IN/OUT/GND pin labels

CONNECTOR LABELS
----------------
  J1   — "J1 UART2" with pin 1 marker and "GND RX2 TX2 3V3" pin labels
  J2   — "J2 USB-C" label
  D1   — "D1 OLED" label with "GND VCC SCL SDA" pin labels

BOARD REFERENCE DESIGNATOR PLACEMENT
--------------------------------------
All reference designators (U1, U2, U3, C1–C8, R1–R6, SW1–SW5, etc.) must be:
  - Placed on silkscreen layer
  - Not overlapping component pads or courtyard areas
  - Readable orientation (no upside-down text)
  - Minimum text height: 0.8 mm (JLC requirement)

# 安全控制台重新设计 — 需求文档

## 功能需求

### FR-1: 指标条 (MetricBar)
将原来 3 行 12 张统计卡片合并为 1 行紧凑指标条，展示 6 个核心 KPI：总请求数、拦截威胁数、成功率、P99 延迟、活跃连接、高危发现。每个指标带趋势箭头（较上一周期的变化百分比）。

### FR-2: 系统资源仪表盘 (SystemGauges)
用 4 个环形进度条展示 CPU、内存、磁盘、网络使用率，替代原来的 4 张独立统计卡片。

### FR-3: 流量趋势图重构
保留面积图，增加 7 天时间范围选项（1h / 24h / 7d）。时间范围选择器移至页面顶部 Header 区域。

### FR-4: 威胁情报面板
将"攻击来源"和"攻击向量分布"合并为一个 Tab 切换面板。

### FR-5: 安全运营面板
将"活跃规则"和"近期操作"合并为一个 Tab 切换面板。

### FR-6: 实时日志流重构
- 保留筛选、暂停、导出功能
- 改为全宽布局
- 日志条目改为紧凑行 + 左侧级别色条
- 筛选器内联到日志区域顶部

### FR-7: 页面 Header 重构
将时间范围选择器、暂停/恢复、导出按钮统一放到页面顶部 Header 右侧。

### FR-8: 管理员区域
API 密钥管理保持不变，仅 admin 可见，放在页面底部。

### FR-9: 组件拆分
将 Dashboard.tsx 中的内联组件拆分为独立文件，放在 `components/dashboard/` 目录下。

### FR-10: i18n 支持
所有新增文案需同时更新 zh.json 和 en.json。

## 非功能需求

### NFR-1: 响应式
桌面端 12 列网格，平板 2 列，移动端单列。

### NFR-2: 性能
保持现有的 4 秒轮询 + WebSocket 实时推送机制不变。减少不必要的重渲染（子组件 memo 化）。

### NFR-3: 可访问性
所有交互元素保留 aria-label，Tab 切换支持键盘导航。

### NFR-4: 测试兼容
保留或更新 `data-testid` 属性，确保现有 E2E 测试不被破坏。

### NFR-5: 主题适配
继续使用 CSS 变量（`hsl(var(--xxx))`），确保 light/dark/system 三种主题正常工作。

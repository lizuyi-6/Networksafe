## JCST Debate-Driven Draft

This directory contains a JCST-oriented research paper draft for AetherGuard.
It is intentionally separate from `papers/SCI-main` because the writing goal is
different:

- focus on debate-driven multi-agent security triage
- keep only claims that can be traced to repository artifacts
- reserve private labeled-alert results for a later revision

### Files

- `manuscript.tex`: main LaTeX entrypoint
- `submission.tex`: single-file submission version generated by `build-submission.ps1`
- `build-submission.ps1`: flattens `manuscript.tex` by expanding all `\input{}` directives
- `references.bib`: editable bibliography source list retained for later export
- `sections/07-references.tex`: inlined bibliography used for stable local builds
- `sections/`: six body sections plus an artifact appendix
- `figures/`: compiled vector PDF figures used by the manuscript
- `author-metadata-template.md`: fill-in template for replacing the anonymous author block
- `private-alert-report-template.md`: fill-in template for the second evidence layer

### What This Draft Does

- fixes the paper position around three contributions only
- removes unverified production-scale claims from the narrative
- uses the repository OWASP-derived evaluation as the public evidence layer
- keeps a placeholder reporting table for future private labeled-alert data

### Build

The draft now compiles with the repository-bundled `tectonic` binary without relying on external BibTeX output.

Working draft:

```powershell
cd papers\JCST-debate
..\..\docs\papers\ieee-access-submission\.build-tools\tectonic\tectonic.exe -k --keep-logs manuscript.tex
```

Single-file submission draft:

```powershell
cd papers\JCST-debate
.\build-submission.ps1
..\..\docs\papers\ieee-access-submission\.build-tools\tectonic\tectonic.exe -k --keep-logs submission.tex
```

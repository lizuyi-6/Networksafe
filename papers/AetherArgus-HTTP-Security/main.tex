\section*{Data, Code, and Evidence Availability}
The repository contains the training and evaluation programs, frozen protocols, model and prompt manifests, per-sample predictions, machine-readable metrics, bootstrap and McNemar outputs, figures, tables, and claim-to-evidence mappings. The paper evidence baseline is merge commit \commitid. The frozen reference-label file is identified by SHA-256 \labelhash. Raw human-review worksheets and reviewer identities are not publicly released because the review was conducted in a restricted environment over confidential benchmark and operational material; the repository instead provides a hash-bound operator attestation and explicitly records this limitation.

\section*{Ethics and Responsible Deployment}
All challenge traffic was collected in an authorized LAN environment. The study does not claim that \model{} is suitable for autonomous blocking. The evaluated model is best interpreted as a shadow-mode or second-stage analytical component. High-risk actions remain outside the model and require independent policy or hardware authorization.

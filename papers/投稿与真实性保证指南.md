# AetherGuard 学术论文投稿与真实性保证指南

> **真实性更新（2026-07-27）**：投稿前必须以 `docs/reports/software-validation-status-2026-07-27.md` 和对应 JSON 为当前软件证据。当前 4,500 条合成语料结果为 63.97% 检测率和 0% 合成正常样本 FPR；Rust 固定 key loopback 复测为三轮 56.6k–61.6k QPS、短扫描峰值 75.1k。旧版 32 样本 OWASP 指标、1,329.79 QPS、6.22% CPU、99.64 MB，以及 100k/资源/AI 强主张都不能替代新的可复现实验。没有外部 OWASP Benchmark 数据、ModSecurity URL、真实模型或 live 服务时，应标为未验证而不是补写结果。

## 三、 LaTeX 投稿打包实操指南 (LaTeX Compilation & Submission)

在选定期刊后，通常需要生成符合期刊排版要求的 PDF 并提交 LaTeX 源代码包。以下为本地打包与编译实操步骤：

### 1. JCST 论文打包与编译 (Springer Nature 模板)
JCST 使用 Springer Nature 模板进行审稿。
在 `papers/JCST-debate/` 下已经内置了扁平化打包脚本 `build-submission.ps1`，它能将各子章节文件（`sections/`）合并展开为一个单文件 `submission.tex`，方便投递系统解析。

**步骤：**
1. **替换匿名信息**：如果需要去匿名化投递，请参考 [author-metadata-template.md](file:///x:/repos/Networksafe/papers/JCST-debate/author-metadata-template.md) 替换 `manuscript.tex` 中的作者块。
2. **运行打包脚本**：
   打开 PowerShell，进入目录并运行：
   ```powershell
   cd papers/JCST-debate
   ./build-submission.ps1
   ```
3. **本地编译 PDF 预览**：
   项目内置了无需外部依赖的 `tectonic` 编译二进制：
   ```powershell
   ../../docs/papers/ieee-access-submission/.build-tools/tectonic/tectonic.exe -k --keep-logs submission.tex
   ```
4. **提交文件准备**：
   投稿时向 ScholarOne 系统上传以下内容：
   - `submission.tex` (合并后的 LaTeX 源码)
   - `figures/` 目录中的矢量图表（PDF/PNG 格式，论文中引用的插图）
   - `sn-jnl.cls` 和 `sn-mathphys-num.bst` (Springer Nature 样式模板)

### 2. SCI-main 论文编译 (IEEE Transactions 模板)
`papers/SCI-main` 针对 IEEE TDSC/TIFS 等双栏排版要求：

**步骤：**
1. 打开 `papers/SCI-main/AetherGuard-SCI-Final.tex`。
2. 确认 `sections/` 中的各个章节文件内容正确。
3. **本地编译方法**（需本地安装有 LaTeX 发行版，如 TeX Live）：
   ```bash
   pdflatex AetherGuard-SCI-Final.tex
   bibtex AetherGuard-SCI-Final
   pdflatex AetherGuard-SCI-Final.tex
   pdflatex AetherGuard-SCI-Final.tex
   ```
   或者直接将 `papers/SCI-main` 下的全部文件打包上传至 **Overleaf** 在线协同编译，在 Overleaf 菜单中将 Compiler 设为 `pdfLaTeX`，主文件设为 `AetherGuard-SCI-Final.tex` 即可。

### 3. 投稿辅助材料清单 (Extras)
投稿系统通常需要以下非正文文件，这在 `docs/papers/ieee-access-submission/` 目录下均有可供参考的模板：
* **Cover Letter (求职信)**：说明论文的创新性及为何适合该期刊。可参考 [cover-letter.txt](file:///x:/repos/Networksafe/docs/papers/ieee-access-submission/cover-letter.txt)。
* **Biography (作者简介)**：IEEE Transactions 最终录用时需要提供作者的简历与高清照片。
* **Data Availability Statement (数据可用性声明)**：指明实验数据的开源路径。可参考 [data-availability.txt](file:///x:/repos/Networksafe/docs/papers/ieee-access-submission/data-availability.txt)。

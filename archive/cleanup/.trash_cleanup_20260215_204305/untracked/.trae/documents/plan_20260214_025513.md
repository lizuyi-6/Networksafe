## 模拟生产环境部署方案

### 部署架构
```
┌─────────────────────────────────────────────────────────────────┐
│                    Docker 生产环境容器                           │
│                                                                  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐  │
│  │   Redis      │  │   Backend    │  │   Frontend (Nginx)   │  │
│  │   :6379      │  │   :3005      │  │   :80                │  │
│  └──────────────┘  └──────────────┘  └──────────────────────┘  │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │              Probe Agent (探针)                           │   │
│  │  • 采集容器内的系统指标                                    │   │
│  │  • 通过 WebSocket 连接 Backend                            │   │
│  │  • 实时上报心跳和威胁数据                                  │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### 将创建的文件

1. **`deployment/production/docker-compose.prod.yml`** - 生产环境 Docker Compose 配置
   - Redis (数据缓存/速率限制)
   - Backend (API + WebSocket Gateway)
   - Frontend (Nginx 静态服务)
   - Probe Agent (探针)

2. **`deployment/production/.env.production`** - 环境变量配置
   - JWT 密钥、Redis 密码等安全配置
   - Agent API Key 配置

3. **`deployment/production/deploy.ps1`** - 一键部署脚本
   - 构建镜像
   - 启动服务
   - 健康检查

4. **`deployment/production/nginx.conf`** - Nginx 配置
   - 静态文件服务
   - API 反向代理
   - WebSocket 代理

### 部署后效果
- 访问 `http://localhost` 查看 Dashboard
- Probe Agent 自动连接 Backend 并开始上报数据
- Dashboard 实时显示 Agent 状态和系统指标

## 修复方案

### 1. 初始化 WebSocket 网关 (server.ts)
- 导入并实例化 `AgentGateway`
- 调用 `setAgentGateway` 使其可用于路由
- 确保 WebSocket 服务器正确附加到 HTTP server

### 2. 集成 TrafficInterceptor (server.ts / ai-system.ts)
- 创建 TrafficInterceptor 实例并启动
- 将其事件连接到 WebSocket 广播
- 修改 API 路由使用真实流量数据

### 3. 统一事件协调
- 创建事件协调器连接各模块
- 攻击分析结果同步更新到 ProbeAgent 统计
- 流量事件广播到前端监控

### 4. 修正前端 WebSocket 端口
- 使用正确的端口连接 WebSocket（后端默认 3005，前端配置 3010）

### 需要修改的文件
1. `backend/src/server.ts` - 初始化 WebSocket 和 TrafficInterceptor
2. `backend/src/routes/ai-system.ts` - 集成真实数据源
3. `backend/src/traffic-interceptor/index.ts` - 添加事件广播接口
4. `frontend/src/pages/AttackSimulator.tsx` - 修正端口配置

### 预期效果
- 攻击模拟运行时，多智能体监控显示实时队列和案例
- 流量拦截器显示真实流量数据
- 各模块形成联动，数据实时同步

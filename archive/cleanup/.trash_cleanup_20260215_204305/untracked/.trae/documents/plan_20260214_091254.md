## 问题分析

AttackSimulator 页面 UI 显示混乱，所有内容挤在一起，没有正确的卡片布局和分隔。

**根本原因**：
1. 使用了 `bg-surface/50` 这样的透明度语法，但 Tailwind CSS 配置中使用 CSS 变量的方式可能不完全支持 `/50` 透明度修饰符
2. 部分样式类如 `backdrop-blur`、`rounded-2xl` 等可能在生产构建中没有正确生成

## 修复计划

### 1. 修复颜色类使用方式
- 将 `bg-surface/50` 改为 `bg-surface` 或使用标准颜色如 `bg-gray-900/50`
- 将 `border-border` 改为 `border-gray-700/50` 等标准颜色
- 确保所有颜色类使用 Tailwind 原生支持的方式

### 2. 简化样式类
- 使用更可靠的 Tailwind 类组合
- 添加明确的背景色和边框色
- 确保卡片有清晰的视觉分隔

### 3. 重新构建和部署
- 修改完成后重新构建前端
- 重新构建 Docker 镜像并部署

# 演示环境创建计划

## 一、创建内容

### 1. 演示专用 Docker Compose
- `demo/docker-compose.demo.yml` - 完整的演示环境配置
- 包含：FluxGuard 后端、易受攻击的测试网站、Redis、攻击模拟器

### 2. 易受攻击的测试网站
- `demo/vulnerable-app/` - 故意设计有漏洞的网站
- 包含漏洞：SQL 注入、XSS、路径遍历、命令注入
- 用于测试防御能力

### 3. 攻击模拟脚本
- `demo/attack-simulator/` - 自动化攻击测试工具
- 支持多种攻击类型模拟
- 实时显示防御结果

### 4. 演示启动脚本
- `demo/start-demo.ps1` - Windows 一键启动
- `demo/start-demo.sh` - Linux/Mac 一键启动

## 三、使用方式

```bash
# 1. 进入演示目录
cd demo

# 2. 一键启动 (Windows)
.\start-demo.ps1

# 3. 访问
#    - 测试网站: http://localhost:8080
#    - 防御面板: http://localhost:3005
#    - 攻击模拟: 自动运行

# 4. 停止演示
docker-compose -f docker-compose.demo.yml down
```

## 四、演示场景

1. **SQL 注入攻击** - 测试 AI 识别和阻断
2. **XSS 攻击** - 测试模式匹配和语义分析
3. **路径遍历** - 测试快速路径检测
4. **DDoS 模拟** - 测试速率限制
5. **混合攻击** - 测试多智能体辩论决策

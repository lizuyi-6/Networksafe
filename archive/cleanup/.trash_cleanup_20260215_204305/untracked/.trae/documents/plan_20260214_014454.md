## 部署 Probe Agent 到 Docker 生产环境模拟

### 目标
在 Docker 中部署一个独立的 Probe Agent 容器，采集真实的系统指标并发送到 Backend。

### 实现步骤

1. **创建 Agent 独立模块** (`agent/` 目录)
   - 创建 `agent/package.json` - 依赖配置
   - 创建 `agent/tsconfig.json` - TypeScript 配置
   - 创建 `agent/src/index.ts` - Agent 入口文件
   - 创建 `agent/src/metrics-collector.ts` - 真实系统指标采集器
   - 创建 `agent/Dockerfile` - 容器构建文件

2. **Agent 功能设计**
   - 采集真实系统指标：CPU、内存、磁盘、网络
   - 通过 WebSocket 连接到 Backend
   - 定期发送心跳和指标数据
   - 支持动态注册和认证

3. **更新 Docker Compose**
   - 添加 `probe-agent` 服务
   - 配置网络连接到 `fluxguard-net`
   - 设置环境变量连接 Backend

4. **数据流向**
   ```
   Probe Agent 容器
        ↓ WebSocket
   Backend API (localhost:3005)
        ↓
   Dashboard 展示真实数据
   ```

### 文件变更
- 新建: `agent/` 目录及所有文件
- 修改: `demo/docker-compose.demo.yml` 添加 agent 服务

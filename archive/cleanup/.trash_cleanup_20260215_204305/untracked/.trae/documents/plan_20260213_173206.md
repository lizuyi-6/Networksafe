# 前端集成计划

## 一、新增页面组件

### 1. Multi-Agent 监控页面 (`/agents-monitor`)
- 显示 7 层架构状态
- 各 Agent 心跳和健康状态
- 辩论协议统计
- 模型路由统计

### 2. 流量拦截器页面 (`/traffic`)
- 实时流量统计
- 协议分布图表
- 威胁检测统计
- 流状态监控

### 3. 攻击模拟页面 (`/attack-sim`)
- 攻击类型选择
- 实时攻击结果
- 防御效果统计

- 添加新菜单项

### 4. 更新国际化文件
- 添加新页面的中英文翻译

## 三、后端 API 端点

需要添加以下 API 端点：
- `GET /api/agents/stats` - Agent 系统统计
- `GET /api/agents/health` - Agent 健康状态
- `GET /api/traffic/stats` - 流量统计
- `GET /api/traffic/flows` - 活跃连接
- `POST /api/attack/simulate` - 执行攻击模拟

更新 `docker-compose.demo.yml` 确保前端正确连接后端

## 问题分析

前端 API 路径和后端路由不匹配：

**后端路由配置：**
- `app.use('/api', aiSystemRoutes)` - 路由挂载在 `/api` 下
- 后端实际路径：`/api/agents/stats`、`/api/traffic/stats`

**前端错误调用：**
- `fetchAgentSystemStats` 调用 `/api/ai-system/agents/stats` ❌
- 应该调用 `/api/agents/stats` ✅

## 修复方案

修改 `frontend/src/services/api.ts` 中的 API 路径：

1. `/api/ai-system/agents/stats` → `/api/agents/stats`
2. `/api/ai-system/agents/health` → `/api/agents/health`
3. `/api/traffic/*` 路径正确（已经是 `/api/traffic/stats` 等）

修改后重新构建前端并部署。

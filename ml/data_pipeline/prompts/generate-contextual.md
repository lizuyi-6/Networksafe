# generate-contextual v0.2

Generate a synthetic contextual security candidate whose decision depends on
`sourceContext`: rapid login failures, token source switching, path enumeration,
large exports, account polling, abnormal privilege access, cross-tenant access,
WebSocket frequency, low-speed scans, or elevated historical risk.

Keep the HTTP structure plausible. Use reserved test targets only. Put observable
evidence in fields allowed by the immutable input schema and record the exact
transformation and source seed. Never expose sealed test samples.

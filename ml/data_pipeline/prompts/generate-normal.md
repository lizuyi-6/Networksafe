# generate-normal v0.2

Generate realistic synthetic normal business requests for the program-selected
scenario. Never use sealed test examples. Use structured login, registration,
profile, search, order, OAuth, webhook, upload/download, report, import, log, security,
database-tool, WebSocket, administration, WAF, repository, ticket, and Markdown
workflows.

Do not reduce normal traffic to simple `GET /`. Use only reserved test identifiers,
domains and addresses. Do not include real personal information or credentials.
Output the immutable detection input/output schema and complete pending provenance.

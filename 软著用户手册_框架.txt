第1页：系统概述
================

1.1 软件简介
------------
API安全中间件管理系统是一款专业的API安全防护解决方案，提供多层次的安全防护机制，包括反机器人保护、速率限制、并发控制、认证安全等功能。系统采用现代化的前后端分离架构，前端使用React + TypeScript，后端使用Express.js + TypeScript，支持分布式部署和容器化运行。

1.2 主要功能特点
----------------
- **多层安全防护**：集成反机器人检测、速率限制、并发控制等多重安全机制
- **实时监控**：提供实时的请求统计、威胁分布、系统性能监控
- **自动化扫描**：内置安全漏洞扫描器，自动检测API安全漏洞
- **部署向导**：提供可视化的部署配置向导，支持Nginx和Apache
- **多语言支持**：支持中英文界面切换
- **容器化部署**：提供完整的Docker和Docker Compose部署方案

1.3 技术架构
------------
- **前端技术栈**：React 18 + TypeScript + Vite + Tailwind CSS
- **后端技术栈**：Express.js + TypeScript + Redis
- **数据库**：Redis（用于分布式状态管理）
- **部署方式**：Docker容器化部署
- **安全标准**：符合OWASP API安全规范

第2页：系统安装与部署
=====================

2.1 环境要求
------------
- **操作系统**：Windows 10/11, Linux (Ubuntu 20.04+), macOS 10.15+
- **Node.js**：版本18.0.0或更高
- **Redis**：版本6.0或更高
- **Docker**：版本20.10或更高（可选）
- **内存**：至少4GB RAM
- **磁盘空间**：至少2GB可用空间

2.2 安装步骤
------------
1. **克隆代码仓库**
   ```bash
   git clone https://github.com/your-repo/api-security-middleware.git
   cd api-security-middleware
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **配置环境变量**
   复制.env.example文件为.env，并根据实际情况修改配置：
   ```bash
   cp .env.example .env
   ```

4. **启动Redis服务**
   ```bash
   # 使用Docker启动Redis
   docker run -d --name redis -p 6379:6379 redis:alpine

   # 或者使用系统安装的Redis
   redis-server
   ```

5. **启动后端服务**
   ```bash
   cd backend
   npm run dev
   ```

6. **启动前端服务**
   ```bash
   cd frontend
   npm run dev
   ```

第11页：安全防护功能详解
========================

11.1 反机器人保护
-----------------
系统采用多层次的反机器人检测机制：
- **用户代理分析**：检测可疑的用户代理字符串
- **请求频率检测**：基于滑动窗口算法的请求频率检测
- **快速请求检测**：检测自动化脚本的快速连续请求
- **蜜罐字段检测**：检测机器人填写的隐藏表单字段
- **IP自动封锁**：对恶意IP自动实施临时封锁

11.2 速率限制机制
-----------------
速率限制采用Redis支持的分布式算法：
- **滑动窗口算法**：精确控制每分钟请求数量
- **原子操作**：使用Redis原子操作防止竞态条件
- **标准HTTP头**：返回X-RateLimit系列标准头信息
- **优雅降级**：Redis故障时自动降级为宽松模式

11.3 并发控制
-------------
并发控制保护系统免受过载攻击：
- **每用户限制**：限制每个用户的并发请求数量
- **队列管理**：对超出限制的请求进行排队处理
- **性能监控**：实时监控系统性能和资源使用
- **自动清理**：自动清理过期和异常的连接

第12页：故障排除与技术支持
==========================

12.1 常见问题解决
-----------------
**问题1：系统无法启动**
- 检查Redis服务是否正常运行
- 检查环境变量配置是否正确
- 查看日志文件中的错误信息

**问题2：前端无法访问后端API**
- 检查CORS配置是否正确
- 检查网络连接和防火墙设置
- 验证API地址和端口配置

**问题3：安全规则不生效**
- 检查NODE_ENV环境变量是否为production
- 检查Redis连接是否正常
- 查看安全日志中的错误信息

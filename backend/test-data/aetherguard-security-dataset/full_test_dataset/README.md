## 📊 样本格式

每个样本包含以下字段：

```json
{
  "id": "sqli_0001",
  "type": "sql_injection",
  "payload": "' OR '1'='1",
  "severity": "high",
  "expected_detection": true,
  "source_ip": "192.168.1.100",
  "timestamp": "2026-03-13T21:00:00"

```

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识符 |
| `type` | 攻击类型 |
| `payload` | 攻击载荷 |
| `severity` | 严重程度 (critical/high/medium/low/none) |

| `timestamp` | 时间戳 |

## 📈 计算公式

### 检测率 (Detection Rate)

```
检测率 = 检测到的攻击数 / 总攻击数 × 100%

例: 检测到 1045 个攻击，总共 1100 个
检测率 = 1045 / 1100 × 100% = 95.0%
```

### 误报率 (False Positive Rate)

```
误报率 = 误判的正常请求数 / 总正常请求数 × 100%

例: 3 个正常请求被误判为攻击，总共 200 个正常请求
误报率 = 3 / 200 × 100% = 1.5%
```

### 准确率 (Accuracy)

```
准确率 = (检测到的攻击数 + 正确放行的正常请求数) / 总样本数 × 100%

例: 检测到 1045 攻击，正确放行 197 正常请求
准确率 = (1045 + 197) / 1300 × 100% = 95.5%
```
